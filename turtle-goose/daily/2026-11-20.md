# TURTLE GOOSE · 개발 회차 11 · 2026-11-20

## 쟁점과 가상 토론

수로의 배에서는 마지막 친구의 위치를 알려주지만, 화물장과 식당의 출구에서는 같은 상황에 집결 안내만 나온다. Unity 에디터를 찾을 수 없어 실제 표식 검사는 보류하고 구역 간 여행의 집결 규칙을 연결했다.

| 역할 | 제안 | 반론과 응답 |
| --- | --- | --- |
| A · Unity 개발 | 마지막 친구 위치 판정을 모든 출구에서 사용한다. | B는 구조 전에도 출구로 유도할 수 있다고 했다. 기존 출구 해제와 대기 판정이 성립할 때만 적용한다. |
| B · 레벨·동선 | 보리와 식당 친구를 데려가는 마지막 구간에 위치 안내를 주자. | C는 여러 친구를 동시에 표기하면 집결 방향이 흐려진다고 했다. 한 명만 늦었을 때 기존 목표 표식을 사용한다. |
| C · 테크 아트·가독성 | 기존 표식에 친구의 이름을 연결한다. | D는 모두 모인 뒤에도 이름이 남으면 다음 공간으로 못 가는 것처럼 보인다고 했다. 승선·집결 계산을 사용해 즉시 출구 목표로 돌아간다. |
| D · 사운드·서사 리듬 | 구조에서 다음 공간으로 이동하는 사이 친구를 챙기는 행동을 돕자. | A는 매번 도착 효과음이 반복될 수 있다고 했다. 기존 텍스트와 위치 표식으로 표현한다. |

## 결정과 실제 변경

구조를 마치고 출구에 도착했을 때 마지막 한 친구가 늦으면 그 친구의 위치를 목표로 표시한다. 함께 모이면 출구로 돌아와 식당 또는 수로로 이어갈 수 있다. 기존 수로 API는 유지하고 공통 집결 판정을 추가했다. 변경 경로는 `JourneyRules.cs`, `MarshHud.cs`, `Tools/JourneyChecks/Program.cs`다.

- .NET 8 JourneyChecks 99개 통과. 화물장 출구에서 보리 위치, 식당 두 진입 경로의 마지막 친구 위치와 출구 복귀를 검사했다. 기존 수로 판정, 구조, 포획 후 재시도, 완료 저장 재개, 4인 LAN 루프백도 통과했다. 동료 위치를 통제하는 규칙 검사다.
