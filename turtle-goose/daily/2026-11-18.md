# TURTLE GOOSE · 개발 회차 09 · 2026-11-18

## 쟁점과 가상 토론

전 회차에서 출구는 미구조 친구를 알려줬지만, 평소 목표판은 한 친구를 구한 뒤에도 두 친구를 함께 언급했다. Unity 실기동은 보류하고 구조 순서와 체크포인트에서 다시 시작할 때의 안내를 맞췄다.

| 역할 | 제안 | 반론과 응답 |
| --- | --- | --- |
| A · Unity 개발 | 남은 우리를 기존 구조 상태에서 직접 읽자. | B는 순서를 강제할 수 있다고 했다. 둘 다 열리기 전까지 두 구조 순서를 모두 허용한다. |
| B · 레벨·동선 | 하나가 비면 목표판에 남은 우리를 알려주자. | C는 새 표식이 기존 목표와 겹칠 수 있다고 했다. 목적지 표식은 유지하고 문구만 바꾼다. |
| C · 테크 아트·가독성 | 이름과 E 홀드 동작을 한영으로 같이 표시한다. | D는 구출 직후 안내가 길면 템포가 끊긴다고 했다. 기존 목표판에서 한 문장으로 표시한다. |
| D · 사운드·서사 리듬 | 둘 다 모이면 기존 봄의 테라스 안내로 자연스럽게 넘긴다. | A는 타이머를 넣으면 재시작 시 상태가 어긋날 수 있다고 했다. 저장된 구조 상태만 읽어 즉시 안내를 고른다. |

## 결정과 검증

`JourneyText.cs`와 `MarshHud.cs`의 목표판을 실제 우리 해제 상태에 연결했다. 한 친구를 구하면 나머지 친구의 우리에서 E를 길게 누르라고 안내한다. 둘을 구하면 봄과 함께 테라스로 향하는 목표가 열린다.

- .NET 8 JourneyChecks 88개 통과. `Tools/JourneyChecks/Program.cs`에 두 친구 미구조, 모를 구한 저장값, 봄을 구한 저장값, 둘 다 구한 저장값의 안내 검사를 추가했다. 화물장·식당 두 경로·수로, 포획 후 재시도, 완료 저장 재개와 로컬 4인 LAN도 통과했다.
- 동봉 글꼴의 한글과 ZIP 무결성을 확인했다. Unity Play Mode와 실제 화면·음향, PC 빌드, 에디터 재시작 후 저장, 외부 플레이테스트, 실제 프리팹 교체는 미검증이다.
