# TURTLE GOOSE · 개발 회차 12 · 2026-11-21

## 쟁점과 가상 토론

식당 테라스의 엄폐는 걷는 발소리를 줄이지만, 기존 규칙에서는 등껍질 구르기도 완전히 조용했다. 빠르게 탈출하는 구르기의 소리 위험이 엄폐 경계에서 사라졌다. Unity의 마지막 친구 표식 검사는 에디터를 사용할 수 없어 보류하고 이 잠입 규칙을 검사했다.

| 역할 | 제안 | 반론과 응답 |
| --- | --- | --- |
| A · Unity 개발 | 구르는 동안 실제 움직임이 있으면 엄폐에서도 기존 구르기 청각 범위를 적용하자. | B는 엄폐가 시야에도 무효가 될 수 있다고 했다. 시야와 엄폐 판정은 그대로 사용하고 청각 조건만 바꾼다. |
| B · 레벨·동선 | 경비 옆 테라스에서 기다리거나 구르는 선택에 다른 결과를 주자. | C는 모양을 바꾸면 사용자 아트 작업과 충돌한다고 했다. 기존 테라스와 순찰 동선으로 검사한다. |
| C · 테크 아트·가독성 | 경비가 들었다는 기존 HUD 상태로 결과를 알리자. | D는 소리가 두 번 겹칠 수 있다고 했다. 새 클립은 추가하지 않고 기존 구르기와 경계 상태를 사용한다. |
| D · 사운드·서사 리듬 | 엄폐에서 조용히 기다리는 행동과 빠른 구르기의 위험을 읽게 하자. | A는 제자리에서 막힌 구르기까지 들리면 부자연스럽다고 했다. 기존 실제 이동 속도 조건을 유지한다. |

## 결정과 코드

`JourneyRules.cs`에서 엄폐 안의 이동 중 구르기도 가까운 경비에게 들리게 했다. 시각적 엄폐는 계속 적용된다. 기존 종 소음이 가리는 평상시 발소리 규칙과 구르기 청각 반경을 사용한다. `Tools/JourneyChecks/Program.cs`의 실제 테라스 이동 검사로 확인했다.

## 실행한 검증

- .NET 8 JourneyChecks 102개 통과. 테라스에서 순찰 옆에 조용히 대기, 엄폐 안에서 구르기 시작 후 경비의 청각 감지, 시야에 잡히지 않아도 경계도가 오르는 결과를 확인했다.
- 기존 코드에서는 같은 구르기 청각 검사가 실패했다. 화물장·식당 두 경로·수로, 구조와 구역 이동, 포획 후 재시도, 완료 저장 재개 및 4인 LAN 루프백도 회귀 검사를 통과했다.
- ZIP 무결성과 C# 두 파일 및 이 기록만 바뀜을 확인했다. Unity Play Mode의 표식·실제 소리·난이도, PC 빌드, 에디터 재시작 후 저장, 외부 플레이테스트, 실제 아트 교체는 미검증이다.
