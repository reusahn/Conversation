# 신인호 포트폴리오 리뷰 · 2026-11-10

첫 번째 개선 사이클의 페르소나 대화를 작업 기록에서 정리했다. 세 관점과 점수는 포트폴리오 개선을 위한 시뮬레이션이다.

## 리뷰 대화

**채용담당자:** Python 도구가 실제로 동작한다는 걸 페이지에서 바로 확인할 수 있으면 좋겠어요. 다운받아 실행할 수 있는 예제와 결과를 먼저 보여주세요.

**12년 경력 테크니컬 아티스트:** 스키마만 보면 잘못된 입력을 어떻게 처리하는지 알 수 없어요. 프레임레이트가 누락된 테이크를 차단하고, 수정한 테이크만 다시 검사하는 흐름을 같은 CLI로 검증합시다.

**팀장:** 다른 아티스트도 재현할 수 있어야 해요. 실패 원인과 수정 방법을 리포트에 남기고, 실행 명령과 종료 코드도 같이 제공합시다.

**합의:** 모션 테이크를 사전 검사하는 Python CLI를 만들고, 실패 → 수정 → 재검사 과정 전체를 다운로드 패키지로 제공한다.

## 반영 및 검증

- 테이크 매니페스트를 읽고 소스 경로, 필수 메타데이터, 중복 ID와 대상 경로를 검사하는 Python CLI를 상세페이지에 반영했다.
- Python 3.12.14에서 합성 샘플 두 건을 검사했다. 한 건은 통과했고 프레임레이트가 빠진 한 건은 차단됐다. 프레임레이트를 채운 뒤 해당 테이크만 다시 검사해 통과했다.
- 다운로드 패키지에서 같은 결과를 재현했고, 설치된 Maya·Unreal 에디터 내 테스트는 아직 진행 전이다.

| 검토 관점 | 내부 점수 | 남은 증거 |
| --- | ---: | --- |
| 채용담당자 | 78/100 | 직무와 연결되는 플레이어블 시연 |
| 테크니컬 아티스트 | 54/100 | 에디터 연동과 런타임 검증 |
| 팀장 | 66/100 | 다른 아티스트의 인수인계 및 실행 기록 |

다음 사이클은 기존 검사 결과를 Maya 씬 검사 또는 Unreal 임포트 사전 검사로 연결하는 범위를 정한다.
