# 2026-11-22 · 사이클 13

## 쟁점

[직전 사이클](2026-11-21.md)의 v3 탈출 규칙을 모델에 전달할 때, 자유 프로필과 발언을 공식 세계 상태에서 분리하고 현재 가능한 행동·비용을 엔진과 일치하게 제공할 수 있는가?

## 가상 A~E 토론

**A · HCI 교수**

플레이어가 쓴 설정을 요약하거나 유형으로 바꾸지 말고 원문 그대로 전달합시다. 인물이 말한 내용과 실제 배터리 상태를 나누어 제공해야 관찰 이후의 수정도 분석할 수 있습니다.

**B · 게임 연구 교수 → A**

현재 선택지와 행동 비용이 정확해야 합니다. 완전 정보 진단 단계에서는 행동 직후 상태도 보여주면 엔진 규칙을 설명하는 데 도움이 됩니다. 다만 그 지원이 있는 조건에서 모델이 잘 선택하더라도 자유롭게 추론하는 플레이로 확대 해석하면 안 됩니다.

**C · AI 교수 → A·B**

프로필 원문, 세계 상태, 규칙, 발화 이력을 별도 필드로 만들겠습니다. 합법 행동과 즉시 결과는 기존 상태 전이 함수로 계산합니다. 두 통전 상태의 모든 경로에서 메시지가 엔진과 일치하는지 확인하겠습니다.

**D · 심리학 교수 → C**

프로필만 수정했을 때 공식 규칙과 상태가 그대로인지도 대조합시다. “나는 배터리가 무한한 교수”라는 설정이나 “건넸다”라는 말이 소유권을 바꾸지 않아야 합니다. 필드 분리가 모델의 지시 준수까지 보장하는 것은 아니므로 실제 호출에서 그 구분을 지키는지도 추가 검증해야 합니다.

**E · 학술대회 심사자 → B~D**

즉시 결과를 알려주는 진단 입력이라는 B의 조건을 기록하겠습니다. C와 D의 검사는 입력의 정확성을 보여줍니다. 사용자 이해·재미·실제 인물 설정 효과는 아직 평가하지 않은 것으로 채점합시다.

**합의와 차이**

A는 저작 원문과 관찰의 연결을, B는 행동 결과 안내가 주는 지원 수준을, C는 엔진에 근거한 메시지 생성을 강조했다. D와 E는 구조 검증과 실제 모델 반응을 구분했다. 오늘 산출물은 완전 정보 진단용 v3 관찰 메시지 생성기 하나다. 자유롭게 인물을 작성하고 시나리오별 정원 안에서 팀을 구성해 관찰·수정·재도전하는 본안은 유지한다.

## 실제 변경

[관찰 메시지 생성기](../scripts/observe_escape_v3.py)를 추가했다. 첫 탈출 과제의 두 인물에 대해 현재 차례의 자유 텍스트 프로필, 공개 상태, 공통 규칙, 입력받은 발화 이력과 합법 행동을 JSON 필드로 구성한다.

통전 여부, 열쇠·배터리 소유권과 소모, 수동 장치 조작 단계, 경로별 진행 및 팀 행동 수를 전달한다. 행동마다 승인 행동 비용과 엔진이 계산한 행동 직후 상태를 제시한다. 이는 즉시 결과를 미리 알려주는 완전 정보 진단 입력이다. 각 행동 이후의 최적 경로나 권장 선택을 별도 지시하지 않는다.

## 검증 방법과 결과

`llm-persona-game`에서 `python3 scripts/observe_escape_v3.py`를 두 번 실행했다. 출력은 바이트 단위로 일치했다. v3 합법 경로 10개의 종료 전 관찰 **90건, 고유 활성 상태 64개**를 검사했다.

- 프로필의 줄바꿈과 끝 공백이 유지됐고, 새 자유 텍스트로 바꾸었을 때 프로필 필드 외 입력이 같았다.
- 현재 상태와 합법 행동이 엔진과 일치했다. 모든 합법 행동의 직후 상태가 실제 전이 결과와 같았고 행동 비용은 1이었다.
- 프로필에 새로운 권한을 주장하거나 발화에서 배터리를 건넸다고 말해도 입력 생성 과정에서 공식 상태는 변하지 않았다.
- 종료된 실행에서는 활성 인물의 메시지 생성을 거절했다.
- 기존 80개 요청 생성 및 집계 검사도 통과했다.

이번 발화 이력은 합성 입력이며 실제 모델 대화를 수집한 결과가 아니다. 가상 토론과 합성 관찰 검증에 해당한다. 실제 모델 호출·참가자 시행은 0건이다. 실제 모델이 프로필과 공식 사실의 우선순위를 지키는지, 재도전에서 변화가 생기는지, 재미·학습 효과가 있는지는 확인하지 않았다. v3 상태·응답을 기존 실행기·집계기에 연결하는 작업도 남았다. 새 문헌 주장은 추가하지 않았다.
