# LLM 페르소나 게임 연구

플레이어가 직업, 배경, 성향과 관계를 자유롭게 작성해 팀을 구성한다. 팀의 대화와 행동을 관찰하고 인물이나 조합을 수정해 재도전한다. 초기 연구는 엔진이 행동과 성공 여부를 판정하는 탈출 과제에 집중한다.

가상 A(HCI), B(게임), C(AI), D(심리학), E(학술대회 심사)가 쟁점과 다음 작업을 검토한다. 날짜별 기록에는 대화, 평가, 실제 변경, 검증 결과와 다음 작업을 남긴다. 가상 검토, 합성 점검, 실제 모델 실험과 사용자 평가의 근거 수준을 구분한다.
