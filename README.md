## 기록 원칙

- 사용자가 확인할 수 있는 대화, 가상 페르소나의 발언, 연구안 수정과 검증 결과를 보존합니다.
- 발언 원문과 후속 정리·수정안을 구분합니다.
- 가상 심사 점수는 실제 학술 심사 결과나 실험 효과를 뜻하지 않습니다.
- 실제 측정, 합성 시험, 가정, 미확인 사항을 구분합니다.
- 이 저장소는 공개 상태이며, 다른 대화나 연구의 기록은 별도 폴더에 둡니다.
- 향후 대화의 저장은 해당 대화에 저장소 접근 권한과 내용이 제공되는 실행 환경에서 수행됩니다. 이 저장소 자체가 ChatGPT의 모든 새 메시지를 자동으로 수집하지는 않습니다.
