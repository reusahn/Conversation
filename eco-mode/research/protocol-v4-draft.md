# Eco 선택의 자발적 성능 교환과 실제 소비 — v4 초안

2026-10-28. 사용자의 이번 명시적 방향 수정에 따른 새 연구 목표다. v3의 ‘품질 비열등성 AND 에너지 감소’ 목표와 점수 이력은 보존한다. v4에서 품질 비열등성은 성공의 필수조건이 아니다. 실측·모델·사람 자료는 없고 새 실행·확증 분석은 비활성이다. 기존 analysis_prepare.py의 v3 공동판정을 이 목표에 그대로 사용하지 않는다.

## 사용자가 밝힌 견해와 연구 질문

사용자는 성능이 낮아질 수 있음을 받아들이면서 자연을 아끼기 위해 Eco를 선택할 수 있다고 생각한다. 실제 토큰과 환경 부담이 줄어드는지 궁금하며, 예상과 다른 결과도 연구할 가치가 있다고 본다. 이것은 한 연구자의 견해이고 모든 참가자가 같은 기대·동기·선호를 가진다는 자료가 아니다.

새 중심 질문: **성능이 낮아질 수 있음을 알고 선택하는 Eco 모드는, 실제 사용 과정에서 토큰과 에너지 소비를 줄이는가? 사용자는 어떤 성능 교환을 받아들이며, 인식한 환경 이익은 확인 가능한 환경 영향과 어떻게 일치하거나 어긋나는가?**

환경 부담 감소는 장기 목표이며 직접 토큰으로 증명하지 않는다. 실제 전력 측정의 경계와 위치·시간별 배출/물 등 영향 추정은 별도로 보고한다. ‘자연환경 훼손 방지’ 전체를 한 장비의 실험으로 입증했다고 하지 않는다.

## 비교와 공통 안내

동일 모델의 실제 low/high 운영 설정과 같은 작업·설명·색·위치·기본값 없음·가격/사용정책을 유지하고, 참가자 사이 낮은 설정의 Low/Fast/Eco 이름만 다르게 제시하는 비교안을 유지한다. Low가 반드시 저품질이거나 Eco가 반드시 절약한다고 가정하지 않는다.

세 집단 모두 낮은 예산은 일부 과제에서 오류가 늘거나 성능이 낮아질 수 있음을 같은 문구로 안내하는 초안을 사용한다. 실제 두 설정의 제어와 안내의 사실성이 확인되어야 참가자 화면으로 동결할 수 있다. 현재 문안은 승인·이해도 검증 완료가 아니다.

명칭만의 총효과와 환경 동기만의 인과효과는 다르다. 환경을 생각했다는 사후 응답은 동기/해석 보고이고 행동의 인과 매개 증명이 아니다. 예상 성능·환경 의미를 본실험 첫 선택 직전에 자세히 질문해 선택 자체를 바꾸는 문제를 줄이기 위해, 사전 기대가 필요하면 독립 지각 표본으로 분리하는 기존 후보를 유지한다. 사후 질문으로 그 사람의 실제 사전 신념을 복원했다고 하지 않는다.

‘성능 저하 가능성을 안내받음’, ‘이를 이해함’, ‘성능 저하를 받아들였다고 사후 말함’, ‘실제로 성과가 낮아짐’은 서로 다른 관측이다. 이해·수용·기억의 사후 응답으로 주 분석 참가자를 선별하지 않는다.

## 결과의 역할

| 항목 | v4에서의 역할 |
|---|---|
| 실제 세션 에너지 | 핵심 자원 결과. 재시도·상향전환·실패·포기·할당 유휴·취소 drain을 포함하며 측정 경계 유지 |
| 토큰 | 핵심 사용 결과. input/reasoning/final-output/total의 제공 의미와 캐시를 구별하고 중복 합산하지 않음. 토큰 감소를 J 감소로 대체하지 않음 |
| 모드 선택·전환·요청 | 명칭의 행동 효과와 사용 과정. 같은 사람의 반복을 독립 참가자로 세지 않음 |
| 객관적 최종 성과·완료율·시간·실패 | 사용자가 실제로 포기하거나 얻은 성능을 설명하는 결과. 비열등성 통과를 자원 결과의 사전조건으로 요구하지 않음 |
| 기대·이해·수용·만족·환경 이익 인식 | 사용자 해석과 교환 수용의 보조/탐색 결과. 자기보고만으로 실제 품질·환경 이익을 입증하지 않음 |

품질 측정을 삭제하지 않는다. 두 arm의 성공률이 모두 낮거나 Eco에서 포기가 증가해 총에너지가 낮아진 경우, 소비 감소와 낮은 성과를 함께 보고한다. 일을 덜 완수한 결과를 ‘같은 일을 더 효율적으로 했다’고 부르지 않는다. 완료자만 남긴 분석이나 성공 과제당 비율 하나로 전체 결과를 대체하지 않는다.

성능이 떨어진 사용을 관측하는 것과 환경 때문에 그 손해를 기꺼이 받아들였다는 의사를 입증하는 것은 다르다. 사후 만족도, 수용도, 목표/제약과 최종 성과를 함께 해석하고 선택 편향·사후 합리화 가능성을 한계로 남긴다.

## 결과와 기여 후보

| 가능한 결과 | 연구가 밝힐 수 있는 내용 |
|---|---|
| Eco 선택 증가 + 토큰/J 감소 + 성과 하락 | 이 고정 작업/시스템에서의 실제 자원 절감과 성능 교환. 사용자 수용은 별도 근거로 설명 |
| Eco 선택 증가 + 토큰 감소 + J 감소 미확인 | 토큰 절감과 계측 에너지 결과의 불일치 |
| Eco 선택 증가 + 재시도/전환 증가 + J 증가 | 친환경을 연상시키는 선택이 총소비 감소로 이어지지 않는 조건 |
| 환경 이익 인식 증가 + 실측 절감 없음 | 인식과 실제 소비의 간극. 환경 동기의 인과 매개나 기만 여부 전체를 자동 판정하지 않음 |
| 정밀한 추정에서 작거나 반대인 효과 | 제시된 이름·작업·시스템에 대한 효과 크기와 한계 |
| 넓은 불확실성·불완전 자료 | 미해결. 유의하지 않음을 무효과·동등성·환경 안전의 증명으로 부르지 않음 |

예상과 반대/무효과도 연구 결과가 될 수 있지만, 그것만으로 출판·채택이 보장되지 않는다. 질문의 새로움·근거의 타당성·추정 정밀도·투명한 분석과 해석이 필요하다. 현재는 투고용 실증 결과가 없다.

## 분석·과제·운영에서 새로 동결할 항목

세 조건과 두 명칭 대비를 유지할지, 주 대비와 핵심 결과를 무엇으로 둘지, 다중비교·최소 관심 효과·표본·정지 규칙을 v4 목표에 맞춰 효과 관측 전에 다시 동결한다. 기존 v3의 네 주장·NI 허용폭·IUT 수치규칙을 v4의 성공 조건으로 재사용하지 않는다. 현재 새 가족·최종 N·새 분석 구현은 미정이다.

품질 허용폭 δ를 v4의 필수 성공 관문에서 제거할 수 있지만, objective scoring contract·task completion·사용 맥락별 수용 판단은 여전히 필요하다. 측정한 품질 차이의 해석·불확실성은 보고한다. 품질 유지라는 추가 주장을 하는 경우에만 그에 맞는 별도 사전 분석이 필요하다.

코딩은 자동채점 도구 준비의 후보다. 코딩으로 분야를 확정하지 않으며, 다른 작업을 포함하면 그 작업별 평가·계측 경계·반복측정과 표본 근거를 갖춰야 한다. 분야·과제의 에너지 기초값 차이를 명칭 효과와 섞지 않는다.

지금은 장비 질문·구매·유료 사용·참가자 모집을 요구하지 않는다. 실제 실행 단계에는 지원되는 에너지 계측 경로와 접근권·시간/지출 상한, 모델 제어 근거, 실제 사용자 단계의 적용 절차·독립 자료가 필요하다. 가상 역할은 참가자의 선택이나 실제 장비 자료를 대신하지 않는다.
