# v4에서 필요한 다음 근거

2026-10-28. 사용자 요청으로 목표를 수정했다. 지금 장비 사양·결제·참가자 모집에 답할 필요는 없다. 코딩은 아직 후보이며 분야를 확정하지 않았다.

## 더 이상 필수 성공 관문으로 두지 않는 것

- 품질 비열등성 또는 동일 품질의 입증은 토큰/J 변화의 결과를 보고하기 위한 필수조건이 아니다.
- 따라서 v3의 NI 허용폭 δ를 모든 v4 실험의 의무 입력으로 요구하지 않는다.
- low 충분성 p_min도 그 분류를 실제 연구에 채택할 때만 필요하다.

이는 성능 결과를 숨기거나 측정 타당성·실제 자료를 생략한다는 뜻은 아니다. 평가할 최종 산출물·완료/오류·unknown의 구분과 성능 교환의 해석은 필요하다.

## 실제 실행 전에 남은 것

| 단계 | 필요한 결정·근거 |
|---|---|
| 연구 범위 | 어떤 작업·사용자·사용 맥락에서 비교할지. 자동채점 코딩 후보와 다른 분야를 함께 일반화하지 않음 |
| 안내와 선택 | 실제 두 설정에 맞는 공통 성능 저하 가능성 안내·기능·사용성, 안내/이해/선택/수용의 분리 |
| 기술 경로 | 실제 모델의 두 예산 적용, 제공되는 토큰 필드·캐시/추론 포함관계, 계측 장비/서버 접근권·경계·불확실성 |
| 분석과 자료 | v4 핵심 결과·주 대비·다중비교·최소 관심 효과·표본/정지 규칙·누락 처리와 새 분석, 독립 예비자료 |
| 사람 단계 | 적용 절차·동의·모집·실행 운영과 실제 선택/성과 자료. 가상 F는 실제 참가자를 대신하지 않음 |
| 환경 해석 | 직접 J, 필요한 자료가 있을 때의 조건부 탄소·물 추정, 현재 확인하지 못한 자연 훼손/장기 반동의 범위 |

총토큰만 확보된 단계도 그 범위의 사용량 결과로 보고할 수 있으나, 전기/환경 질문이 해결됐다고 하지 않는다. 유효한 계측이 있어도 생태계 훼손 방지 전체를 입증한 것으로 확대하지 않는다. 실제 접근 가능한 경로를 선택한 뒤 그 경로에 필요한 정보만 순서대로 확인한다.

## 평가의 뜻

여섯 역할은 `rubric-v4.md`를 심사 전에 고정하고 같은 통합 문서 버전을 읽었다. A–E는 새 목표에 대한 설계/실행 준비도의 가상 평가이며, F는 실제 사용자 견해에 대한 문서의 취지 충실도이다. 둘은 같은 종류의 점수가 아니며 평균을 내지 않는다. 옛 v3 점수와도 직접 비교하지 않는다.

통합본의 충실한 방향 수정과 실제 연구의 완성은 별개다. F 취지 충실도100은 사용자 새 승인이나 다른 역할의 실행 결손을 대신하지 않는다. 전원100을 선언할 근거는 아직 없다.
