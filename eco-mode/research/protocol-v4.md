# Eco 선택의 성능 교환과 실제 소비 — v4 검토 반영안

2026-10-28. 사용자의 이번 명시적 방향 수정에 따른 새 연구 목표다. v3의 ‘품질 비열등성 AND 에너지 감소’ 목표와 점수 이력은 보존한다. v4에서 품질 비열등성은 성공의 필수조건이 아니다. 실측·모델·사람 자료는 없고 새 실행·확증 분석은 비활성이다. 기존 analysis_prepare.py의 v3 공동판정을 이 목표에 그대로 사용하지 않는다.

## 사용자가 밝힌 견해와 연구 질문

사용자는 성능이 낮아질 수 있음을 받아들이면서 자연을 아끼기 위해 Eco를 선택할 수 있다고 생각한다. 실제 토큰과 환경 부담이 줄어드는지 궁금하며, 예상과 다른 결과도 연구할 가치가 있다고 본다. 이것은 한 연구자의 견해이고 모든 참가자가 같은 기대·동기·선호를 가진다는 자료가 아니다.

새 중심 질문: **성능 저하 가능성을 공통 안내한 상황에서, 같은 낮은 연산 설정을 Eco로 제시하면 사용자의 선택과 총토큰·에너지 소비는 어떻게 달라지는가? 사용자가 받아들이는 성능 교환과 기대하는 환경 이익은 실제 성과·소비·확인 가능한 환경 영향과 어떻게 일치하거나 어긋나는가?**

주 추정대상은 모든 원배정 참가자의 명칭 총효과다. 안내를 받았다는 사실이 그 내용을 실제로 이해하거나 환경 때문에 성능 저하를 자발적으로 수용했다는 뜻은 아니다. 실제 이해·수용·동기는 별도 관측 질문으로 남기고, 그 사후 응답으로 주효과 표본을 선별하지 않는다.

환경 부담 감소는 장기 목표이며 직접 토큰으로 증명하지 않는다. 실제 전력 측정의 경계와 위치·시간별 배출/물 등 영향 추정은 별도로 보고한다. ‘자연환경 훼손 방지’ 전체를 한 장비의 실험으로 입증했다고 하지 않는다.

## 비교와 공통 안내

동일 모델의 실제 low/high 운영 설정과 같은 작업·설명·색·위치·기본값 없음·가격/사용정책을 유지하고, 참가자 사이 낮은 설정의 Low/Fast/Eco 이름만 다르게 제시하는 비교안을 유지한다. Low가 반드시 저품질이거나 Eco가 반드시 절약한다고 가정하지 않는다.

세 집단 모두 낮은 예산은 일부 과제에서 오류가 늘거나 성능이 낮아질 수 있음을 같은 문구로 안내하는 초안을 사용한다. 실제 두 설정의 제어와 안내의 사실성이 확인되어야 참가자 화면으로 동결할 수 있다. 현재 문안은 승인·이해도 검증 완료가 아니다.

명칭만의 총효과와 환경 동기만의 인과효과는 다르다. 환경을 생각했다는 사후 응답은 동기/해석 보고이고 행동의 인과 매개 증명이 아니다. 예상 성능·환경 의미를 본실험 첫 선택 직전에 자세히 질문해 선택 자체를 바꾸는 문제를 줄이기 위해, 사전 기대가 필요하면 독립 지각 표본으로 분리하는 기존 후보를 유지한다. 사후 질문으로 그 사람의 실제 사전 신념을 복원했다고 하지 않는다.

‘성능 저하 가능성을 안내받음’, ‘이를 이해함’, ‘성능 저하를 받아들였다고 사후 말함’, ‘실제로 성과가 낮아짐’은 서로 다른 관측이다. 이해·수용·기억의 사후 응답으로 주 분석 참가자를 선별하지 않는다.

## 결과의 역할

| 항목 | v4에서의 역할 |
|---|---|
| 실제 세션 에너지 | 핵심 자원 결과. 재시도·상향전환·실패·포기·할당 유휴·취소 drain을 포함하며 측정 경계 유지 |
| 토큰 | 핵심 사용 결과. input/reasoning/final-output/total의 제공 의미와 캐시를 구별하고 중복 합산하지 않음. 토큰 감소를 J 감소로 대체하지 않음 |
| 모드 선택·전환·요청 | 명칭의 행동 효과와 사용 과정. 같은 사람의 반복을 독립 참가자로 세지 않음 |
| 객관적 최종 성과·완료율·시간·실패 | 사용자가 실제로 포기하거나 얻은 성능을 설명하는 결과. 비열등성 통과를 자원 결과의 사전조건으로 요구하지 않음 |
| 기대·이해·수용·만족·환경 이익 인식 | 사용자 해석과 교환 수용의 보조/탐색 결과. 자기보고만으로 실제 품질·환경 이익을 입증하지 않음 |

품질 측정을 삭제하지 않는다. 두 arm의 성공률이 모두 낮거나 Eco에서 포기가 증가해 총에너지가 낮아진 경우, 소비 감소와 낮은 성과를 함께 보고한다. 일을 덜 완수한 결과를 ‘같은 일을 더 효율적으로 했다’고 부르지 않는다. 완료자만 남긴 분석이나 성공 과제당 비율 하나로 전체 결과를 대체하지 않는다.

성능이 떨어진 사용을 관측하는 것과 환경 때문에 그 손해를 기꺼이 받아들였다는 의사를 입증하는 것은 다르다. 사후 만족도, 수용도, 목표/제약과 최종 성과를 함께 해석하고 선택 편향·사후 합리화 가능성을 한계로 남긴다.

## 결과와 기여 후보

| 가능한 결과 | 연구가 밝힐 수 있는 내용 |
|---|---|
| Eco 선택 증가 + 토큰/J 감소 + 성과 하락 | 이 고정 작업/시스템에서의 실제 자원 절감과 성능 교환. 사용자 수용은 별도 근거로 설명 |
| Eco 선택 증가 + 토큰 감소 + J 감소 미확인 | 토큰 절감과 계측 에너지 결과의 불일치 |
| Eco 선택 증가 + 재시도/전환 증가 + J 증가 | 친환경을 연상시키는 선택이 총소비 감소로 이어지지 않는 조건 |
| 환경 이익 인식 증가 + 실측 절감 없음 | 인식과 실제 소비의 간극. 환경 동기의 인과 매개나 기만 여부 전체를 자동 판정하지 않음 |
| 정밀한 추정에서 작거나 반대인 효과 | 제시된 이름·작업·시스템에 대한 효과 크기와 한계 |
| 넓은 불확실성·불완전 자료 | 미해결. 유의하지 않음을 무효과·동등성·환경 안전의 증명으로 부르지 않음 |

예상과 반대/무효과도 연구 결과가 될 수 있지만, 그것만으로 출판·채택이 보장되지 않는다. 질문의 새로움·근거의 타당성·추정 정밀도·투명한 분석과 해석이 필요하다. 현재는 투고용 실증 결과가 없다.

## 분석·과제·운영에서 새로 동결할 항목

세 조건과 두 명칭 대비를 유지할지, 주 대비와 핵심 결과를 무엇으로 둘지, 다중비교·최소 관심 효과·표본·정지 규칙을 v4 목표에 맞춰 효과 관측 전에 다시 동결한다. 기존 v3의 네 주장·NI 허용폭·IUT 수치규칙을 v4의 성공 조건으로 재사용하지 않는다. 현재 새 가족·최종 N·새 분석 구현은 미정이다.

품질 허용폭 δ를 v4의 필수 성공 관문에서 제거할 수 있지만, objective scoring contract·task completion·사용 맥락별 수용 판단은 여전히 필요하다. 측정한 품질 차이의 해석·불확실성은 보고한다. 품질 유지라는 추가 주장을 하는 경우에만 그에 맞는 별도 사전 분석이 필요하다.

코딩은 자동채점 도구 준비의 후보다. 코딩으로 분야를 확정하지 않으며, 다른 작업을 포함하면 그 작업별 평가·계측 경계·반복측정과 표본 근거를 갖춰야 한다. 분야·과제의 에너지 기초값 차이를 명칭 효과와 섞지 않는다.

지금은 장비 질문·구매·유료 사용·참가자 모집을 요구하지 않는다. 실제 실행 단계에는 지원되는 에너지 계측 경로와 접근권·시간/지출 상한, 모델 제어 근거, 실제 사용자 단계의 적용 절차·독립 자료가 필요하다. 가상 역할은 참가자의 선택이나 실제 장비 자료를 대신하지 않는다.


## 여섯 역할의 반론을 반영한 채택 사항

### 품질의 역할과 결과 분석 전환

품질/완료율/사용시간은 성능 교환의 비용을 설명하는 결과다. v3의 품질 비열등성 허용폭 δ와 IUT는 v4의 자원 감소를 인정하기 위한 필수 성공 관문이 아니다. low 충분성 기준 p_min도 그 분류를 별도로 채택할 때만 필요하며 모든 v4 분석의 의무 관문으로 이월하지 않는다. 개별 최종 산출물의 성공/오류를 구별하는 평가 계약과 누락 처리는 필요하다.

모든 배정자와 과제의 완료·실패·포기·unknown을 보존하고, 조건별 자원 소비와 성과를 함께 제시한다. 품질이 낮아졌다는 이유로 자원 결과를 숨기거나 삭제하지 않는다. 자원이 줄었다는 이유로 같은 과제를 더 효율적으로 완료했다고 해석하지 않는다. 실제 성과가 같아지는 경우도 허용하며 ‘Eco는 항상 저품질’이라는 전제를 강제하지 않는다.

### v4의 분석 우선순위 — 동결 전 제안

단독 연구의 범위를 줄이기 위한 제안은 Eco–Low를 주 대비, Eco–Fast를 속도 연상 명칭과의 별도 비교로 두는 것이다. 실제 표본·문헌·사용 맥락 확인 뒤 효과 관측 전에 이 우선순위를 동결한다. 사용자가 세 조건을 이미 최종 선택했다고 간주하지 않는다.

주 대비에서 총토큰과 세션 에너지의 변화는 서로 다른 결과다. 토큰 감소·J 감소를 각각 추정하며 둘 모두 줄어야 연구가 성립한다는 새 공동 성공 조건을 만들지 않는다. 증가·감소·작은 차이·넓은 불확실성을 모두 보고할 수 있도록 양측 구간/검정을 우선 검토한다. 두 결과를 확증적으로 함께 판정한다면 사전에 다중비교를 통제해야 한다. 예를 들어 Holm 수준 .05는 후보일 뿐 최종 등록이나 유효성 검증 완료가 아니다. Fast 비교·선택/수용·성과/과제 차이의 검정 지위도 동결해야 한다.

지금은 정확한 새 검정법·최소 관심 효과·표본/정지 규칙·검정력·최종 결과 가족을 완성했다고 하지 않는다. 실제 세션 분포와 누락의 원인을 반영하지 않은 채 기존 v3 분석 함수를 호출해 v4 효과가 검증됐다고 보고하지 않는다. 비유의 차이는 무효과나 동등성의 증명이 아니다. 성과·완료 여부·토큰처럼 명칭 이후 달라질 수 있는 변수로 주효과를 임의 보정하지 않는다.

### 토큰 정의와 로그의 포함 관계

| 구분 | 보고 원칙 |
|---|---|
| 논리적 입력 문맥 | 요청에 담긴 문맥의 길이. 서버의 실제 처리량이나 청구 토큰과 같다고 가정하지 않음 |
| 서버 보고 입력 토큰 | 고정한 provider/schema가 뜻하는 input 범위대로 보고. cached가 포함되었는지 확인 |
| cached 입력 부분집합 | input의 부분집합이면 다시 더하지 않음. 요금/계산량 효과는 별도 |
| 생성 completion 전체 | reasoning을 포함하는지 실제 필드 정의와 trace로 확인 |
| 내부 reasoning | completion의 부분집합이면 다시 더하지 않음. 미제공은 null/unknown |
| 사용자에게 보이는 최종 답변 | 내부 reasoning과 별도. 텍스트 재토큰화는 내부 reasoning 복원이 아님 |
| 청구 토큰/비용 | 가격 정책의 단위이며 물리적 연산·J의 증거가 아님 |

각 관측에는 value, unit, source_field, schema_version, inclusion_scope, completeness, source_event_id, attempt_id를 연결하는 명세를 둔다. 실제 API/모델별 adapter가 이를 검증한 상태는 아니다. 권위 있는 최종 누적 usage를 stream chunk 누적값과 다시 합산하지 않는다. 로그 재전송은 중복 제거하되 실제 모델 재실행은 새 attempt로 포함한다. 늦게 도착한 usage도 원래 attempt에 연결한다. 누락/구조 충돌은0으로 채우지 않는다.

입력·생성량을 하나의 총토큰으로 합치는 경우에도 그것이 같은 계산량/에너지 단위라는 뜻은 아니다. 원래 성분과 정의를 함께 보고하고, 포함 관계나 필요한 필드가 확인되지 않으면 완전한 총토큰 결과를 약속하지 않는다. 토큰과 J의 완전성은 각각 평가하므로 한쪽 누락을 다른쪽으로 대체하지 않는다.

### 환경 질문의 세 근거 수준

| 근거 수준 | 보고할 내용 | 확대할 수 없는 결론 |
|---|---|---|
| 직접 측정 | 정한 GPU/시스템/입력 경계의 세션 J 또는 Wh | 데이터센터 전체·사회 전체 자원·생태 훼손 회피 |
| 조건부 추정 | 지역·시간·전력원·냉각 등 필요한 자료가 있을 때 그 가정 아래의 탄소·물 영향과 불확실성 | 자료 없이 보편 환산 상수로 만든 환경 보증 |
| 현재 미확인 | 생태계·자원 채굴·장비 제조·기간 전체 수요/반동에 대한 질문을 열린 한계로 보존 | ‘자연환경 훼손을 막았다’는 직접 실증 주장 |

추정 자료가 없으면0이나 임의 평균을 넣는 대신 추정 불가로 표시한다. 사용자가 기대하는 환경 이익과 실제 확인 가능한 영향의 일치/불일치는 연구 주제로 유지한다. 사용자 인식의 진정성이나 생태 영향 전체를 사후 설문 하나로 판정하지 않는다. 정해진 세션의 절감과 자유로운 장기 사용의 총수요 감소는 별개의 범위다.

### 예상과 다른 결과의 보고와 투고

‘이 결과가 아니더라도’는 사용자가 기대한 절감과 다른 관측 결과도 연구할 가치가 있다는 뜻으로 읽는다. 결과 없는 계획을 완료된 실증 연구처럼 투고하겠다는 의도로 해석하지 않는다. 감소하지 않음·증가·작은 효과도 타당한 설계·정밀한 추정·지식 기여가 있으면 논문으로 발전할 수 있다는 것은 방법상의 판단이며 채택 보장이 아니다.

[CHI 2027 공식 연구 품질 안내](https://chi2027.acm.org/guide-to-a-successful-submission/)와 [심사 기준](https://chi2027.acm.org/authors/papers/papers-review-process/)은 기여·근거의 정합성·독창성·타당성·투명성을 평가한다. 이 안내가 ‘무효과면 자동 채택’ 또는 특정 결과 방향의 의무를 명시한다고 인용하지 않는다. 가까운 환경 라벨/기대 연구가 이미 있으므로 성능 교환을 받아들인다는 아이디어 자체의 최초성을 주장하지 않는다. 실제 두 예산의 사용 과정과 자원·성과·인식의 관계가 추가로 어떤 지식을 주는지가 기여 후보다.

### 현재 완료 범위

이번 작업은 F 가상 역할 추가, 목표 수정, 공개 교차 토론, 새 검토 기준과 v4 설계 반영이다. 새 실제 모델 실행·토큰 실험·센서 계측·사람 실험·통계 코드 검증은 없다. v3 개발 코드/검사 기록은 과거 도구 근거로 보존하되 새 목표의 효과 증거로 승격하지 않는다. 실험 실행·분석/자료 동결 상태는 미완료다.
