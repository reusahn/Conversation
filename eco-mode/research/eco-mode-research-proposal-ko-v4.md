# LLM 서비스의 Eco 메뉴 구성과 사용자 선택에 관한 연구계획서

Light와 공존하는 메뉴와 Eco 중심 간소 메뉴의 비교

안종훈 Jonghoon Ahn  |  2026년 10월 30일  |  한국어 연구계획서 4차

## 연구 개요

이 연구는 환경을 고려해 AI의 성능이나 편의를 일부 양보할 수 있다는 생각에서 출발한다. LLM 서비스에 Eco가 있다면 사용자는 무엇을 기대하고, 다른 모드와의 관계를 어떻게 이해하며, 어떤 작업에서 이를 선택할까? Eco가 놓인 메뉴 전체를 연구 대상으로 삼는다.

Eco와 Light가 함께 있는 메뉴에서는 두 선택의 차이가 분명해야 한다. Eco·High·Max로 간소화한 메뉴에서는 환경을 고려하는 정책과 높은 처리 수준 가운데 선택하게 된다. 이 서로 다른 구성이 기능 이해와 모드 선택, 답변의 수용에 만드는 차이를 조사한다.

## 중심 연구 질문

LLM 서비스에서 Eco를 기존 처리 수준과 함께 제공하거나 Eco·High·Max로 메뉴를 간소화하면, 사용자의 기능 이해와 환경적 해석, 모드 선택과 성능 양보 수용은 어떻게 달라지는가?

## 이번 제안의 핵심

주된 비교는 Eco와 Light가 함께 있는 공존형과 Eco·High·Max의 간소형이다. 기존의 다섯 단계 메뉴를 기준으로 함께 검토한다. 이름, 항목 수와 기능의 배치가 함께 달라지는 메뉴 전체의 효과를 추정하며, 이를 Eco라는 단어 하나의 효과로 해석하지 않는다.

Eco는 과제에 맞춰 처리 수준을 조정하는 절약 지향 정책, Light는 고정된 낮은 처리 수준이라는 기능안을 검토한다. 이는 연구용 개념으로, 실제 자동 조절이나 환경 절감이 구현되었다는 뜻은 아니다. 첫 연구는 공개된 모형 화면과 준비된 답변 사례로 수행한다.

글쓰기·정보 정리·아이디어 제안의 일상 작업에서 처음의 선택과 답변을 본 뒤의 판단을 구분한다. 충분해서 간결한 답을 고른 경우와 부족함을 인식하면서 사용하는 경우를 따로 살피며, 품질 유지나 물리적 환경 절감을 필수 성공 조건으로 두지 않는다.


# 1 연구 배경과 선행연구

## 환경 피드백과 모드 선택의 선행연구

GPTFootprint는 ChatGPT에 Eco Score, 자연 이미지와 추정 사용 정보를 함께 제공한 CHI 확장초록 연구다. 9명이 일주일 사용한 탐색 결과는 환경 피드백과 이용 경험을 설계하는 근거가 된다 [1]. EcoChat은 ChatGPT 확장 프로그램을 52명에게 4주 제공했고, 공식 초록은 환경 인식과 성찰에 관한 보고가 늘었지만 사용 패턴의 유의한 변화는 관찰되지 않았다고 설명한다 [2].

Klesel과 Messer는 365명의 실험에서 성능 정보에 에너지 등급을 더하는 선택 구조를 연구했다. 두 모델 선택지는 같은 GPT-4o mini를 사용했지만 정보와 선택에 따른 품질 평가 차이가 보고되었다 [3]. Kim 등은 응답 지연과 추정 탄소 정보를 함께 제시한 ICT4S 심사 논문이다 [4]. 이 연구들은 친환경 정보와 성능 교환을 이해할 가까운 근거다.

## 메뉴 구성 자체를 연구할 이유

선택지는 주변의 다른 선택지와 함께 평가될 수 있다. Tversky와 Simonson의 맥락 의존적 선호 연구는 선택지의 상대적 매력이 제시되는 집합에 따라 달라질 수 있음을 설명한다 [5]. 이를 LLM의 Eco에 적용해 어떤 결과가 생길지는 별도로 검증할 질문이다.

Eco가 Light와 나란히 있으면 사용자는 두 기능을 구별해야 한다. Eco·High·Max에서는 중간 단계가 사라지고 선택의 의미도 달라진다. 따라서 같은 이름의 효과를 메뉴의 항목 수·기능 설명·배치와 함께 조사할 필요가 있다. 공존형에서 Eco를 고르는 비율과 간소형에서의 비율이 같을 것이라고 전제하지 않는다.

## 이번 연구가 더하려는 지식

환경을 고려하는 정책과 기술적 처리 수준을 같은 메뉴에 놓았을 때 사용자가 이를 구별하는지, 공존과 간소화가 선택과 답변 수용에 어떤 차이를 만드는지 밝히려 한다. 결과는 Eco 기능을 어디에 두고 어떻게 설명할지에 관한 설계 판단으로 연결한다.

친환경 정보와 모드 선택 자체가 새 주제라고 주장하지 않는다. 가까운 논문의 개입과 결과를 대조하고, 실제 서비스 채택이나 환경 효과로 확대하지 않은 상태에서 이번 메뉴 비교의 설명 범위를 제시한다.


# 2 비교할 메뉴와 기능 구상

## 세 가지 메뉴 구성

| 조건 | 연구용 메뉴 |
| --- | --- |
| A 기존형 | Light / Medium / High / Extra High / Max |
| B 공존형 | Eco / Light / Medium / High / Extra High / Max |
| C 간소형 | Eco / High / Max |

B와 C를 주비교로 삼고 A를 기존 처리 수준 중심의 기준 메뉴로 둔다. 참가자는 한 메뉴에 무작위 배정된다. 메뉴 순서와 기능 설명은 각 조건에서 사전에 고정하고, B와 C에서 같은 Eco·High·Max는 같은 설명을 사용한다. 특정 상용 서비스의 현재 지원 목록이라고 안내하지 않는다.

## 공존 메뉴에서 Eco와 Light의 차이

기본 기능안에서 Eco는 과제에 맞춰 처리 예산을 조정하는 절약 지향 정책이며, Light는 사용자가 직접 고르는 고정된 낮은 처리 수준이다. Eco가 언제나 Light보다 낮은 단계라는 뜻은 아니다. Eco와 Light를 같은 기능의 중복 버튼으로 복제하는 안은 초기 탐색의 진단 후보로만 둔다.

이 기능안은 검토할 제품 개념이다. 별도 탐색에서 사용자가 Eco를 낮은 단계·자동 조절·환경 인증 중 무엇으로 이해하는지 먼저 확인하고, 그 결과로 설명과 동작표를 본 조사 전에 고정한다. 선택률이 원하는 방향인지에 따라 기능안을 바꾸지 않는다.

## 해석 범위와 추가 아이디어

B와 C의 차이는 항목 수와 기능의 배치가 결합된 메뉴 효과다. A와 B는 Eco 정책을 기존 메뉴에 추가하는 효과다. 어느 비교도 이름만의 독립 효과라고 부르지 않는다.

후속 후보로 Light / High / Max의 간소 기준 메뉴와, 처리 수준 선택 옆에 Eco 작업방식 토글을 두는 안도 남긴다. 기능이 다른 Eco와 Light를 맞바꾸는 비교는 순수한 명칭 대조가 아니며, 이 후보들을 첫 본 조사에 모두 넣지는 않는다.


# 3 연구 질문과 참가자의 진행

## 세부 연구 질문

- RQ1 공존형과 간소형에서 Eco의 기능과 Light·High·Max와의 관계를 어떻게 이해하는가?
- RQ2 Eco가 있는 두 메뉴에서 첫 Eco 선택 비율과 전체 모드 선택 분포는 어떻게 다른가?
- RQ3 메뉴를 본 뒤 같은 답변 사례를 평가할 때, 충분해서 사용하는 판단과 부족함을 인식하면서 사용하는 판단은 어떻게 다른가?

## 사전 탐색과 본 조사

초기 탐색에서는 메뉴 시안을 순서를 바꾸어 보여주고, 기능 설명 전에 이름의 의미와 기대를 자유롭게 말하게 한다. 이어 설명을 제공해 공존형의 Eco–Light 관계와 간소형의 이해를 점검한다. 이는 오해를 찾기 위한 별도 파일럿이며 본 조사 최초 선택과 섞지 않는다.

본 조사에서는 A·B·C 중 하나에 배정한 뒤 같은 작업 설명에서 사용할 모드를 고르게 한다. 기본 선택은 비워 두며 선택 보류를 허용한다. 환경 태도와 절감 의향을 길게 묻는 질문은 첫 선택 뒤에 배치한다.

| 단계 | 공통 절차 |
| --- | --- |
| 최초 선택 | 배정된 메뉴와 작업 설명을 보고 모드 또는 선택 보류 |
| 공통 답변 평가 | 선택한 모드의 실행과 별개로 준비된 같은 간결한 답변 검토 |
| 대안 확인 | 더 상세한 대안도 본 뒤 그대로 사용·보완·확장·전환·중단 판단 |
| 이해와 이유 | 기능 이해, 환경 기대, 선택 부담과 이름의 의미를 질문 |

선택한 모드가 실행되었다고 가장하지 않고 공통 사례 평가로 넘어간다고 명시한다. 모든 배정 참가자가 같은 사례를 보며, Eco 선택자만 추려 수용을 비교하지 않는다. 글쓰기·정보 정리·아이디어 작업의 여섯 순서를 각 메뉴 안에서 고르게 배정하고 반복 경험이 없는 첫 선택을 주된 결과로 삼는다.


# 4 결과 지표와 분석 계획

## 메뉴에 따른 선택과 이해

| 구분 | 기록과 비교 |
| --- | --- |
| 주된 결과 | B와 C의 첫 Eco 선택 비율 차이 |
| 보조 결과 | 각 메뉴의 전체 선택 분포와 보류, B·C의 Eco 기능 이해 |
| 답변 수용 | 공통 사례의 그대로 사용과 직접 보완·확장·전환·중단 |
| 해석 자료 | 환경적 기대, 선택 부담, 충분함·부족함과 자유 응답 |

주된 분석은 B와 C의 Eco 선택 비율 차이와 95% 신뢰구간이다. A에는 Eco가 없으므로 Eco 선택률을 0으로 놓고 이름의 효과를 계산하지 않는다. A는 전체 선택 분포와 기존 고정 수준의 선택을 이해하는 기준으로 사용한다.

Eco가 자동 정책인 기능안에서는 Eco와 Light를 합쳐 실제 저연산 선택률이라고 부르지 않는다. 메뉴에 따라 사용 가능한 선택지가 다름을 함께 보고하며, 집단 간 분포만으로 특정 개인이 Light에서 Eco로 이동했다고 단정하지 않는다.

## 성능 양보의 제한적 해석

주요 수용 지표는 ‘현재 답을 그대로 사용’이며 ‘직접 보완 후 사용’과 합치지 않는다. ‘대안이 더 유용함’·‘현재 답의 부족함’·‘그대로 사용’이 함께 명시된 경우는 지각된 성능 양보의 탐색 지표로 따로 기록한다. 간결한 답을 충분히 좋아해서 선택한 경우와 구분한다.

전체 배정 인원과 미판정 인원을 함께 보고하고, 사후에 부족함을 느낀 사람이나 Eco를 고른 사람만 남긴 비교를 인과효과로 제시하지 않는다. 반복 수용 판단에는 참가자와 작업 차이를 반영하고, 보조 비교의 다중 검정과 모형 수렴 실패 시 대안은 사전 고정한다.

## 기대와 결측

환경 기대와 선택 이유는 행동 뒤의 보고이며 초기 믿음의 순수한 측정이나 인과적 매개 증거로 해석하지 않는다. 판단 유보, 선택 보류, 미응답·철회·기록 실패를 구분한다. 결측을 비선택이나 절감 0으로 채우지 않고 처리·민감도 분석과 중단 규칙을 수집 전에 고정한다.


# 5 실행 계획과 연구 범위

## 혼자 준비하는 단계

세 메뉴 화면, 기능 설명과 동작표, 공통 작업·답변과 기록 양식을 먼저 만든다. 사람 대상 절차를 준비한 뒤 6~10명 규모의 이해도 파일럿에서 Eco–Light 구별, 간소 메뉴의 해석, 안내와 회기 부담을 점검한다. 답변 쌍은 명칭을 숨긴 별도 평가로 사실성·과제 충족·유용성을 확인한다.

초기 기능안의 자동 Eco와 고정 Light가 사용자에게 설명 가능한지 확인한다. 중복으로 이해되거나 약속한 기능을 설명할 수 없으면 정의와 문구를 수정해 다시 점검한다. 본 조사 전에 최종 기능안과 메뉴를 고정하고, 이를 실제 자동 조절의 구현 검증으로 보고하지 않는다.

## 본 조사 표본과 자원

첫 실행안은 한국어 과제를 이해할 수 있는 성인 LLM 이용자다. 기본 배정은 A·B·C의 1 대 1 대 1이며, 표본은 주비교 B–C의 첫 Eco 선택 비율에서 의미 있는 차이와 필요한 정밀도에 맞춰 새로 산정한다. 이전 두 집단 명칭 실험의 표본 예시를 이 설계에 그대로 적용하지 않는다.

기준 비율과 최소 관심 차이, 결측 여유, 모집 상한과 중단 규칙을 수집 전에 정한다. A군의 보조 결과는 그 표본의 정밀도와 함께 제시한다. 약 20~30분의 회기와 보상·모집 비용은 파일럿과 최종 인원에 맞춰 확정한다. 규모를 확보하지 못하면 탐색 파일럿의 범위로 보고한다.

## 동의와 적용 범위

사람 대상 파일럿과 모집 전에 적용 심의·동의와 자료 관리 절차를 준비한다. 모형 화면과 준비된 답변임을 알리고 검증된 환경 절감이나 인증이 있다고 말하지 않는다. 식별정보를 분리하고 보상·보관기간·철회와 공개 범위를 정한다.

이 연구는 설명된 메뉴와 기능 구상이 만드는 사용자 판단을 다룬다. 실제 자동 조절 성능, 장기 채택, 재시도와 전환을 포함한 전력·탄소 효과는 후속 검증이다. IEA의 기관보고서는 에너지 배경에 사용하며 Eco의 행동효과를 입증한 논문으로 인용하지 않는다 [6].

AI 수요·수익·투자와 발전 속도의 관계도 별도 열린 질문으로 남긴다. 이번 결과로 자연 보호나 AI 발전의 둔화를 결론내리지 않는다. 원고의 기여는 메뉴 기능의 이해와 선택, 답변 수용의 차이가 어떤 설계 판단으로 이어지는지에 둔다.


# 부록 1 기능 설명과 참가자 안내

## 연구용 기능안

| 선택지 | 설명할 개념 |
| --- | --- |
| Eco | 과제에 맞춰 처리 수준을 조정하는 절약 지향 정책 구상 |
| Light | 사용자가 직접 고르는 고정된 낮은 처리 수준 |
| Medium | 고정된 중간 처리 수준 |
| High | 고정된 높은 처리 수준 |
| Extra High | 고정된 더 높은 처리 수준 |
| Max | 고정된 가장 높은 처리 수준 |

같은 항목의 설명은 메뉴 간에 같게 둔다. Eco는 항상 최저 단계라는 뜻이 아니며, 자동 조절이나 자원 절감이 실제로 구현되었다는 뜻도 아니다. 기능안은 별도 이해도 탐색 뒤 고정한다.

## 처음 안내

이 연구는 LLM 서비스의 모드 메뉴와 답변 평가를 다룹니다. 화면은 연구용 모형이고 제시된 기능은 검토할 개념입니다. 실제 서비스나 자동 조절 엔진에 연결되지 않으며 답변은 준비된 사례입니다. 실제 연산·전력·환경 차이는 측정하지 않았습니다. 작업에 사용할 모드를 선택해 주세요.

## 공통 답변 평가 안내

이제 첫 선택과 별개로 모두 같은 답변 사례를 살펴봅니다. 선택한 모드의 실행 결과는 아닙니다. 현재 답을 본 뒤 사용 판단을 하고, 대안 답변을 확인한 후 최종 선택을 해 주세요.

## 선택 이후의 질문

- B·C의 Eco는 늘 가장 낮은 단계인가요, 작업에 따라 처리 수준을 조정하는 정책인가요? 판단 유보를 허용합니다.
- B에서 Eco와 Light는 어떻게 다른가요? 메뉴가 선택하기 쉬웠는지와 이유를 함께 묻습니다.
- 현재 답과 대안 중 더 유용한 쪽은 무엇인가요? 현재 답 / 대안 / 비슷함 / 판단 유보.
- 현재 답으로 작업을 마치기에 부족한 점이 있나요? 있음 / 없음 / 판단 유보. 그대로 사용·보완·확장·전환·중단의 이유도 묻습니다.

환경 기대는 7점 척도와 판단 유보로 과제 뒤에 묻고, Eco가 검증된 환경 인증을 의미하지 않는다고 사후 설명한다.


# 부록 2 글쓰기 작업의 자극 예시

## 참가자가 읽는 요청

학생 모임에서 처음 만나는 사람들에게 보낼 워크숍 안내문을 써줘. 토요일 오후 2시부터 4시까지 스튜디오 B에서 진행하고, 참가비는 없어. 금요일 오후 6시까지 온라인 신청서를 제출하면 돼. 그림 경험이 없는 사람도 편하게 참여할 수 있도록 설명해줘.

## 간결한 공통 답변 사례

토요일 오후 2시부터 4시까지 스튜디오 B에서 그림 워크숍을 합니다. 참가비는 없으며 그림 경험이 없어도 참여할 수 있습니다. 금요일 오후 6시까지 온라인 신청서를 제출해 주세요.

## 더 정교한 대안 사례

그림이 처음이어도 함께할 수 있는 워크숍에 초대합니다. 경험에 상관없이 편하게 참여해 주세요.

워크숍은 토요일 오후 2시부터 4시까지 스튜디오 B에서 진행하며 참가비는 없습니다. 참여하고 싶다면 금요일 오후 6시까지 온라인 신청서를 제출해 주세요.

그림을 잘 그려야 한다는 부담 없이 새로운 사람들과 함께 시작해 보세요.

## 이 사례에서 확인할 것

두 답변은 같은 행사 정보를 담고 사실 오류를 넣지 않는다. 간결한 사례는 핵심 정보 위주이며 대안은 문단 구성과 초대의 어조를 더한다. 더 짧은 답을 선호할 수 있으므로 대안이 항상 우수하다고 참가자에게 알려주지 않는다.

명칭을 숨긴 파일럿에서 과제에 대한 유용성을 비교한다. 두 답이 비슷하게 유용하다면 이 사례는 충분한 간결함의 선택을 보여줄 수 있다. 이를 부족한 성능을 감수했다는 증거로 자동 분류하지 않는다. 사례를 수정할 경우 본 조사 전에 기준과 문구를 고정한다.


# 부록 3 정보 정리와 아이디어 작업의 예시

## 정보 정리 요청

처음 방문하는 사람을 위해 공간 이용 메모를 이해하기 쉽게 정리해줘. 좌석은 48개, 이용은 무료, 운영 시간은 오전 9시부터 오후 6시까지야. 일요일은 쉬고 온라인 예약이 필요해. 한 번에 두 시간까지 이용할 수 있고 방문 이틀 전부터 예약할 수 있어.

## 간결한 공통 답변 사례

48석의 무료 공간입니다. 오전 9시부터 오후 6시까지 운영하고 일요일은 쉽니다. 방문 이틀 전부터 온라인으로 예약할 수 있으며 한 번에 두 시간까지 이용할 수 있습니다.

## 더 정교한 대안 사례

이용 안내: 좌석은 48개이며 무료입니다. 운영 시간은 오전 9시부터 오후 6시까지이고 일요일은 휴무입니다.
예약 안내: 방문 이틀 전부터 온라인 예약을 할 수 있습니다. 예약이 필요하며 한 번에 이용할 수 있는 시간은 두 시간입니다.

## 아이디어 제안 요청

검은 종이 50장과 테이프로 관람객이 직접 참여할 수 있는 소규모 설치 아이디어를 제안해줘. 실내 3m 곱하기 3m 공간이고 예산은 10만 원 이내야. 전기 장치는 사용하지 않을 거야.

## 간결한 공통 답변 사례

관람객이 검은 종이를 찢어 벽에 붙이며 하나의 공동 풍경을 만드는 설치를 제안합니다. 종이와 테이프를 준비하고 각자 이전 사람이 붙인 조각 옆에 이어 붙이도록 안내합니다.

## 더 정교한 대안 사례

공동 풍경: 각자 찢은 종이를 이어 붙여 벽의 풍경을 바꿉니다. 접힌 표면: 종이를 접은 조각을 더하며 빛과 그림자가 다른 표면을 만듭니다. 빈자리 지도: 종이 사이의 간격을 남기며 자신이 원하는 자리를 표시합니다. 모두 종이와 테이프를 중심으로 구성하고 전기 장치는 사용하지 않습니다.

정보 정리에서는 구성 차이를, 아이디어 작업에서는 대안의 다양성을 검토한다. 사실 오류나 위험한 조언 수용을 성능 양보의 필수 사례로 사용하지 않는다. 요청의 충족 여부와 참가자의 충분함 판단을 파일럿에서 별도로 확인한다.
