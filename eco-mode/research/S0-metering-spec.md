# S0 계측 명세 초안

작성: 가상 D 운영 자문, 2026-10-27. 실제 장비·계측값은 아직 없다.
고정 D 심사기준의 실제 확보·실측 요구를 이 명세가 대신하지 않는다.

## 추정 대상과 경계

주 지표는 명시한 한 경계에서 전용으로 할당된 백엔드 서비스 세션의 총에너지다.
GPU 계측이면 해당 GPU만, 외부 입력 전력계면 그 전력계 아래 시스템만 가리킨다.
생각시간의 유휴, 실패·재시도·모드 전환, 운영상 검증, 취소 후 잔여 실행을 포함한다.
그 결과를 일반 데이터센터의 한계 전력, 전체 냉각·물·탄소, 순수 모델 계산 에너지로 확대하지 않는다.

세션 시작은 조건 노출 직전이다. 최종 완료·확정 포기·공통 최대시간 중 먼저 온 사건에서 신규 요청을 막는다.
이미 접수한 실행의 중지 또는 완료를 백엔드에서 확인한 뒤 종료 카운터를 읽는다.
공통 최대시간은 별도 기술·사용성 예비자료로 정해 라벨 효과를 보기 전에 동결한다.
조기 완료 뒤 공통 최대시간까지 불필요하게 계속 할당하는 고정 창은 사용하지 않는다.
실제로 호출하지 않아도 할당 세션의 유휴 에너지가 남을 수 있다. 0으로 확정되는 것은 관측된 무호출의 호출수·토큰이지 누락 에너지가 아니다.

## 장비 확인 관문

실제 모델 실행 전 연구자가 사용할 OS·GPU/메모리·접근권·가용 시간·지출 상한을 확인한다.
현재 도우미 실행호스트는 연구자의 컴퓨터가 아니다.
센서 지원, 측정 경계, 단위, 갱신·해상도·정확도·교정 정보와 원시값 접근 가능성을 확인한다.
장비 구매나 유료 클라우드 사용은 이 문서만으로 승인되지 않는다.
확인할 수 없으면 무지출 문헌·UI·합성 도구 준비로 축소한다.

## 원시 기록

모든 읽기에 다음을 남긴다.

| 필드 | 의미 |
|---|---|
| record_id, session_id | 수정하지 않는 원시 읽기와 세션 식별자 |
| source_id, device_id, scope | 센서·장치와 측정 경계 |
| sensor_epoch, epoch_evidence | 누적값 연속성 구간과 실제 리셋 감시 근거 |
| value_raw, unit_raw | 원단위 누적 카운터. 가능하면 정수 원값 보존 |
| read_begin_mono, read_end_mono | 단조 시계 기준 API 호출 시작·끝 |
| utc_anchor, clock_mapping | 저장용 UTC 대응과 시계 정렬 근거 |
| update_period, lag_bound | 실제 자료로 확인한 갱신·지연 범위. 모르면 null |
| sensor_status, provenance | 정상·누락·미지원과 실측/합성/추정 구분 |

세션·과제·논리 요청·개별 시도의 ID를 분리하고 선택, 요청 접수, 모드 전환, 취소 요청, 실제 backend_stopped/drained, 최종 종료 사건을 남긴다.
프런트엔드 응답 종료는 백엔드 연산 종료의 증거가 아니다.
API 호출 bracket은 센서의 실제 취득시각 보장이 아니다. 갱신 지연의 상한이 없으면 시각 불확실성을 확인했다고 하지 않는다.
같은 epoch 문자열을 두 번 기록한 것만으로 실제 리셋 미발생을 증명하지 않는다. 드라이버·장치 재시작 감시, 누적값 연속 기록 등 실제 감시 근거와 잔여 가정을 남긴다.

## 총량과 검산

검증된 동일 source/device/scope/epoch의 시작·종료 카운터 차이를 한 번만 주 총량으로 계산한다.
단위 변환과 표시용 반올림은 집계 이후 한다.
직렬 시도별 차이의 합은 활성 구간 합계, 주 총량에서 이를 뺀 값은 유휴/미귀속 잔차다.
활성 합계와 잔차를 주 총량에 다시 더하지 않는다.
동일 카운터의 순서 있는 활성 구간이 주 구간 안에 있으면 활성 합계가 주 총량을 초과해서는 안 된다.
음의 잔차는 감사보류 사유다. 실제 센서·집계 근거 없이 임의 tolerance를 넣어 통과시키지 않는다.
원시 주 총량 자체의 유효성과 활성 귀속의 유효성은 별도 필드로 보존한다.

## 무효·누락 규칙

중복 원시/사건 ID가 내용까지 같으면 한 번만 처리한다. 같은 ID의 내용이 다르면 충돌로 중단한다.
서로 다른 단위·범위·장치·epoch 혼합, 카운터 감소, 세션 중첩, 활성구간이 세션 밖, 취소 후 실행종료 미확인, 필수 읽기 누락은 각각 명시적 사유로 남긴다.
무효 또는 누락 에너지는 null이다. 0이나 평균값으로 자동 대체하지 않는다.
장치 오류가 생긴 참가자도 배정군의 선택·품질 자료에서 자동 제거하지 않는다.
시스템 전체의 물리적 상한과 경과시간 등 근거가 있을 때만 누락 에너지의 구간을 구성한다. 근거가 없으면 상한도 null이다.
실제 장치의 리셋이 관측되지 않는다는 가정이 필요하면 이를 숨기지 않는다.

## 불확실성과 검출 가능성

정확도·분해능·갱신 지연·경계 시각·교정·반복 변동을 각각 기록한다.
독립 자료가 뒷받침하는 항만으로 에너지 불확실성 구간을 구성한다. 가정한 숫자를 장치 명세로 쓰지 않는다.
보수적 경계오차를 계산한다면 확인된 에너지 카운터 오차와 검증된 최대전력·시각/갱신 지연의 기여를 결합하되, 명세가 이미 포함한 항을 이중으로 더하지 않는다.
반복 실행의 무작위 변동과 계통 오차는 별도다. 반복 수를 늘려 계통 오차가 사라진다고 주장하지 않는다.

저·고 예산은 같은 과제의 짝지은 블록에서 순서를 무작위화하고 동일 warm/cache 정책과 직렬 실행으로 확인한다.
센서 갱신보다 짧은 작업을 묶어 볼 수 있지만 이는 S0 기술 확인이며 실제 사용자 세션을 대신하지 않는다.
저예산이 반드시 더 적은 에너지를 보여야 통과하는 부호 선별을 하지 않는다. 실제 예산 통제와 목적에 맞는 계측 가능성이 관문이다.
단일 호출의 에너지 차이가 작다는 이유만으로 세션 누적 효과를 검출할 수 없다고 단정하지 않는다.
본실험의 에너지 감소·동등 주장은 실제 세션 경계의 불확실성과 검출 가능성으로 판단한다.
그 판단이 불가능하면 RQ2의 확증적 절감 주장을 차단하고 선택·품질 결과 및 에너지의 불확실성을 보고한다. 불확실함을 효과 없음으로 바꾸지 않는다.

## S0 통과에 필요한 아직 없는 증거

- 확인된 연구 장비·센서 지원·경계·시간·비용.
- 실제 두 예산의 설정·관측 추론/답변 토큰·종료/잘림 로그.
- 실제 원시 카운터, 리셋 감시와 시각/갱신 지연 근거.
- 워밍업·유휴·짝지은 반복의 원시값과 계측 불확실성.
- 선택한 세션 정책에서 목적에 맞는 에너지 효과를 식별할 수 있는 근거.

합성 테스트는 위 기록·집계 규칙의 구현 확인이다. 장비 지원·실측 정밀도·실제 절감의 증거가 아니다.
