# 상용 LLM Eco 연구의 관측·주장 구분

2026-10-28. 연구 설계 구체화이며 실험 자료나 사전등록이 아니다. 기존 점수·평가기준을 바꾸지 않는다.

좋아. **우리가 확인할 수 있는 것은 ‘선택·믿음·서비스 사용량’이고, 전력과 환경 효과에는 추가 근거가 필요해.** 아래는 실험용 채팅 화면에 상용 LLM API를 연결하는 경우를 기준으로 한 구분이야.

| 구분 | 어떻게 확인하나 | 연구에서 말할 수 있는 것 |
|---|---|---|
| **Eco 선택·재질문·모드 전환** | 우리 화면의 행동 기록 | Eco 표시가 사용 행동을 어떻게 바꿨는가 |
| **환경을 아끼려는 의도·절약했다는 믿음** | 설문·인터뷰 | 참가자가 무엇을 기대하고 믿었다고 보고했는가 |
| **답변 성과·완료·포기** | 과제별 평가와 작업 기록 | 사용자가 얻은 결과와 감수한 성능 손해 |
| **입력·출력·추론 토큰** | API가 제공하는 사용량 기록 | 재시도까지 포함한 **보고된 총토큰**의 변화 |
| **낮은 추론 설정 적용** | 요청 설정과 제공자의 확인 가능한 기록 | 어떤 설정으로 요청·처리됐는가. 실제 물리적 연산량 전체는 별개 |
| **전력 사용량** | 해당 요청·세션에 귀속할 수 있는 제공자 측 계측 | 유효한 계측이 있을 때만 실제 전력 변화 |
| **탄소·물 사용량** | 에너지·지역·시간·전력원·냉각 등의 자료 | 자료와 가정이 충분한 범위의 조건부 추정 |
| **자연환경 훼손 감소** | 더 넓은 환경·수명주기·장기 사용 자료 | 이번 API 실험만으로는 확인하기 어려움 |

토큰은 **제공자가 보고하는 사용량**이야. 캐시·추론 토큰의 포함 관계를 확인해 중복 없이 합쳐야 해. 토큰 감소율을 그대로 전력 감소율로 바꿀 수는 없어. 실제 전력 평가에는 서버·유휴 자원·데이터센터 운영 범위까지 고려해야 해. 

그래서 이번 논문의 중심 질문은 이렇게 잡으면 좋아.

> **Eco라는 표시는 사용자의 절약에 대한 믿음과 선택을 어떻게 바꾸며, 실제 추론 설정에 따라 전체 토큰 사용량과 작업 성과는 어떻게 달라지는가?**

여기서 **“낮은 추론 설정을 썼다고 믿었다”**는 실제 설정 기록과 비교할 수 있어. **“환경을 보호했다고 믿었다”**는 응답은 그 믿음이 생겼다는 근거야. 환경 보호가 실제로 일어났는지는 별도로 남겨야 해.

이렇게 하면 네가 궁금해하는 환경 문제를 유지하면서, 이번 연구에서 답할 수 있는 질문도 분명해져.

## 실행 범위

- 연구자가 만든 채팅 UI와 상용 모델 API의 실험이다. ChatGPT 등 실제 소비자 앱의 내부 모델 선택·도구·시스템 프롬프트·서빙 전부를 재현했다고 하지 않는다.
- 일반적인 공개 API 사용량을 서버 전력계로 취급하지 않는다. 원시 API 응답과 계약 버전을 보존하고 입력·출력·추론·캐시의 포함 관계를 제공자별로 확인한다. 기존 declared usage adapter의 부분집합 규칙을 다른 제공자에 무조건 재사용하지 않는다.
- 설정 요청과 제공자 응답의 확인 가능한 적용 근거를 구분한다. low/high는 구성 정책이며 호출별 정확한 FLOPs, 소비 전력, 항상 낮은 토큰/품질을 보장하지 않는다.
- 세션의 모든 원배정자·실패·재시도·전환·취소 잔여 사용을 포함한다. 사용량이 미보고된 attempt는 0이 아닌 unknown이다. 품질 저하는 자원 결과를 보고하기 위한 비열등성 게이트가 아니며 성과/완료와 나란히 보고한다.
- 무작위 label/backend 배정의 효과와 환경 의도 자기보고의 관찰적 연관성을 구분한다. 개인의 미선택 모드 결과는 관측하지 않았다. 동일 backend도 사용자 행동 차이로 총토큰과 전력이 달라질 수 있다.
- 공개 제공자의 평균·중앙 에너지 지표는 그 서비스·시점·방법의 결과다. 우리 조건의 효과로 간주하거나 토큰 절감률에 곱해 물리적 절감량을 만들지 않는다. 조건별 환경 추정에는 적합한 모델/입력자료와 불확실성 검토가 별도로 필요하다. 그런 근거가 없으면 energy_j/carbon/water는 미관측 또는 추정 불가로 둔다.
- 지금은 API 사용·비용 지출·모집·새 모델 실행을 시작하지 않았다. 연구 질문의 해석 범위를 정리한 단계다.
