# v3 분석 명세와 가정

분석 준비용이며 실제 결과·완료된 사전등록이 아니다.

두 대비에서 D_L=mean(L_Eco)−mean(L_control), D_E=mean(E_Eco)−mean(E_control),
D_F,s=mean(F_Eco,s)−mean(F_control,s)를 쓴다. 참가자 한 명이 단위이고 전체 배정 K개 과제가 분모이다.
품질의 필수 overall은 전체K이며 사전 하위 구간도 평가한다.
선택·품질 unknown은 [0,1]로 남긴다. 가장 불리한 식별 상한은 Eco 미관측1, 대조군 미관측0에 해당한다.
이는 값을 확정 대입한 분석이 아닌 식별 경계이다. 에너지 unknown은0이 아니며 현재 함수는 하나라도 불명하면 Welch를 차단한다.

독립 참가자의 [0,1] 결과를 가정하면 평균차 가중항의 범위 제곱합 S=1/n_E+1/n_C이다.
단측 반경 r=sqrt(S*ln(1/α)/2), 양측은 ln(2/α)를 쓴다.
단측 평균차 상한은 관측차+r, 누락이 있으면 식별상한+r이다. 논리 범위[-1,1]로만 자른다.
전원 성공이어도 r는 양수이다. 분산에 따라 유리한 방법으로 바꾸지 않고 같은 준비 규칙을 적용한다.
원 부등식: Hoeffding(1963), https://doi.org/10.1080/01621459.1963.10500830
가중 평균차/누락 경계 적용은 위 수식에 따른 설계상 도출이다.
독립성·무간섭·실제 배정은 코드가 인증하지 않는다. 장비 시간 변화·이전 세션 잔여 영향도 통제·점검해야 한다.
매우 보수적이며 현재δ/N을 정당화하지 않는다.

에너지 준비 함수는 raw J 참가자 평균차의 Welch t 단측 상한이다. 등분산을 가정하지 않지만 임의 왜도/꼬리에서 유한표본 정확성을 보장하지 않는다.
n<2·분산0·누락이면 판정하지 않는다.
설치된 SciPy1.17.0의 ttest_ind(equal_var=False,alternative="less")와 수치 대조 검사했다.
공식 문서: https://docs.scipy.org/doc/scipy-1.17.0/reference/generated/scipy.stats.ttest_ind.html

가족α=.05, 주장4개, 각α=.0125이다. 선택은 양측98.75% 경계이다.
공동주장 내부는 에너지UCB<0 AND overall/모든 사전구간의 실패UCB<δ_s라는 IUT이다.
구성 구간들을 동시신뢰구간이라고 부르지 않는다.
δ는 추가 실패의 절대비율이며 예를 들어 .05는5%p이다. .05가 현재 권고/확정값은 아니다.

manifest·참가자ID·서버 설정 해시·측정경계는 입력 대조 대상이다. 일치가 실제 사람·장비·무작위배정의 진위를 증명하지 않는다.
세션 내 epoch와 세션 간 epoch는 분리한다.
현재 코드의 confirmatory_allowed는 항상false이다.
실제 자원·계측·독립 예비자료·δ·검정력·사전등록·가정을 확인하기 전 통과로 바꾸지 않는다.
