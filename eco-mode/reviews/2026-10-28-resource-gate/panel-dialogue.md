2026-10-28. 이번 요청에 대한 새 공개용 가상 토론이다. A–E는 실제 전문가나 서로 독립된 외부 심사자가 아니다. 아래는 한 작성자가 다섯 전문 관점을 적용해 구성한 대화이며 과거 발언의 복원 원문이 아니다. 기존 연구안·심사기준을 유지한다. 실제 모델 실행·계측·사람 실험·새 검사 실행은 하지 않았다.

**C · AI:** “모델 두 예산은 설정 파일만으로 채택하지 맙시다. 요청에 전달된 값과 실제 backend 적용 근거, 종료·잘림 정보를 연결해야 합니다. 출력이 짧다는 사실만으로 낮은 추론 예산을 인정하지 않습니다.”

**A · HCI:** “품질 허용폭은 결과를 보고 조정하면 안 됩니다. 정한 시점·정한 이유·참고한 자료를 연결하고, 확증 자료의 효과를 본 뒤 바뀌면 변경과 새 분석 지위를 표시합시다.”

**B · 논문:** “단, 이 접수표는 새로운 통계 방법도, 기존 분석 대체도 아닙니다. 기존 관문의 증거를 찾아갈 수 있게 하는 관리 규칙으로 한정합시다. 문서 작성만으로 고정 점수의 감점을 제거하지 않습니다.”

**A · HCI:** “재심사는 새 근거가 해당 감점 항목을 충족하는지 볼 때 진행합시다. 참가자 없는 기술 실험이 끝나도 명칭 효과의 사용자 실험은 미완료로 남습니다.”

**C · AI:** “자료가 불완전하면 기각 또는 보류 이유를 남기되 효과가 예상과 반대라는 이유로 기각하지 않습니다. 제 설계 100점은 실제 모델·센서 통과를 보증하지 않습니다.”

**E · 개발:** “기술 설정이나 센서·채점 버전이 바뀌면 과거 자료를 삭제하지 않고 적용 범위를 표시하겠습니다. 새 버전에 과거 채택을 자동 승계하지 않습니다. 이번에는 접수 규칙만 정했고 구현·검사를 완료했다고 보고하지 않겠습니다.”

**B · 논문:** “합의합니다. 무한 토론 대신 ‘새 근거 없이는 점수 유지’라는 종료 조건을 적용합니다. 연구의 다음 행동은 장비 모델 하나를 확인하는 것입니다. 없는 경우나 모르는 경우도 허용된 답이며, 그 사실에 맞춰 준비 작업을 정합니다.”

## 합의된 결정: 증거 접수 규칙

이 표는 기존 S0·품질·분석 관문의 증거 관리 보완이며 통과 조건을 완화하거나 분석을 교체하지 않는다.

| 단계 | 받을 자료 | 인정 범위 | 여전히 인정할 수 없는 주장 |
|---|---|---|---|
| 자원 보고 | 사용자가 알려준 컴퓨터 모델명, 모름·없음 포함 | 다음 자원 확인 경로의 출발점 | 센서 지원·실행 권한·실측 가능성 확정 |
| 자원 확인 | 접근권·지원 센서·측정 경계·시간 및 지출 조건 근거 | 실행 경로 검토 | 실제 두 예산 작동·에너지 절감 |
| 기술 자료 접수 | 버전 고정 설정·backend 적용·종료/잘림·원시 센서·유휴/반복·drain 로그 | 기존 S0 규칙에 따른 유효성 재심사 | 사용자 명칭 효과·데이터센터 전체 환경 개선 |
| 사용자 실험 준비 | UI→서버→채점 연결, 독립 예비자료, 과제·δ/p_min·공동검정력·자원·적용 절차 근거 | 연구 진행 가능성과 분석 동결 검토 | 본 실험 효과·환경 영향의 실증 |

| 검토 관점 | 담당 증거 | 해당 항목을 재심사할 조건 |
|---|---|---|
| A | 과제 타당성·실용적 허용폭·사람 연구 절차 | 이유와 동결 시점이 남고 최종 과제·모집 조건과 일치함 |
| B | 주장–자료 연결·독립 예비자료·검정력 | 근거가 재현 가능하며 실제 공동 판정과 자원 부담을 다룸 |
| C | 실제 두 예산·모델 평가 | backend 적용·종료/잘림·품질 근거가 동일 버전으로 연결됨 |
| D | 접근권·계측 경계·원시값·운영 자원 | 센서 지원·오차·누락·반복과 비용/시간 경계가 확인됨 |
| E | UI→서버→실행→채점·로그 | 실제 경로에서 식별자·취소/drain·누락 구분과 원시값 연결을 검증함 |

담당자는 실제 승인권자가 아닌 가상 검토 관점이다. 위 조건은 기존 기준 재심사의 입구이며 각 고정 기준의 만점 요구를 대체하지 않는다. 자료가 없으면 `blocked/no_evidence`, 제출됐지만 검토가 끝나지 않으면 `pending_review`로 남긴다.

각 증거는 고유 ID, 연결 주장, 출처, 상태, 제약과 검토 기준을 가진다. 실제 파일이면 위치와 해시·설정 버전을 함께 남긴다. 측정자료이면 시간·단위·경계·누락을 연결한다. 해당하지 않는 항목은 ‘해당 없음’으로 구분한다. 현재는 실측 증거 항목을 채운 레코드를 만들지 않았다.

채택은 담당 고정 기준의 재심사를 열기 위한 근거이고 자동 만점이 아니다. 설정 변경 시 기존 자료의 적용 범위를 검토한다. 장비·모델명만 받았거나 토큰·지연만 확보한 것을 J 실측 관문 통과로 처리하지 않는다. 절감 부호는 자료 유효성의 조건이 아니다.

## 점수와 미해결 조건

기존 완료 점수를 유지한다: **A 92 · B 62.5 · C 설계 100 · D 73 · E 설계 97/실행 증거 50**. 이번 토론에 독립 외부 심사나 새 독립 실행 점수를 부여하지 않았다. 전원 100점은 아니다.

다음 필수 외부 입력은 **연구에 사용할 컴퓨터 모델명**이다. 그다음 해당 경로의 접근권·센서·시간·지출 상한을 확인해야 한다. 실제 모델 예산 제어·에너지 계측·과제와 품질 허용폭·사람 예비자료·표본 근거는 미해결이다. 이 문서를 작성한 것으로 해결됐다고 표시하지 않는다. 현재 `confirmatory_allowed=false`를 유지한다.
