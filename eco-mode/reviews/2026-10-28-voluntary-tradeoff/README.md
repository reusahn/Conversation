# 성능 교환을 받아들이는 Eco 선택 — A–F 토론과 v4

2026-10-28. 사용자는 동일 답변 품질 유지가 필수인지 질문하며, 성능이 낮아질 수 있음을 받아들이고 환경을 위해 Eco를 선택할 때 실제 토큰과 환경 부담이 줄어드는지, 예상과 다른 결과도 연구할 수 있는지를 중심에 두었다. 가상 안종훈 역할을 추가해 함께 토론해 달라고 요청했다.

## 수정된 방향

**품질 유지는 자원 절감의 필수 성공조건에서 제외한다.** 성과·완료율·시간·오류는 무엇을 맞바꾼 선택인지 설명하는 결과로 남긴다. 소비 감소와 성능 저하가 동시에 발생해도 보고할 수 있다. 일을 덜 완수한 것과 동일 성과의 효율 개선은 구분한다.

주 질문은 **성능 저하 가능성을 공통 안내한 상황에서 같은 낮은 연산 설정을 Eco로 제시하면 선택과 총토큰·에너지 소비가 어떻게 달라지는가**이다. 실제 이해·자발적 수용·환경 동기는 별도로 관찰할 질문이며 모든 참가자에게 이미 존재한다고 가정하지 않는다.

[v4 검토 반영안](../../research/protocol-v4.md), [새로 필요한 근거](../../research/requirements-v4.md), [초기 초안](../../research/protocol-v4-draft.md)을 함께 보존한다. 기존 v3 연구안·점수·검증 코드는 소급 변경하지 않는다. v3 NI/IUT 분석을 새 목표의 성공 판정으로 사용하지 않는다. 새 실제 모델/센서/사람 실험·코드 검사는 없다.

## 가상 토론과 수정

| 역할 | 주요 논점 | 공개 기록 |
|---|---|---|
| A HCI | 품질을 관문 대신 교환 결과로, 공통 안내와 실제 이해/수용 구별, 전체 원배정자 유지 | [A-review.md](A-review.md) |
| B 논문 | 예상과 반대/작은 결과도 기여 가능, 무유의성과 정밀한 무효과 구별, 가까운 선행과 새 근거 필요 | [B-review.md](B-review.md) |
| C AI | 실제 성능 저하를 강제하지 않음, input/cached/reasoning/completion/answer의 포함관계와 J 구별 | [C-review.md](C-review.md) |
| D 환경/운영 | 환경 질문 유지, 직접 J/조건부 영향 추정/미확인 생태 영향 분리, 세션과 장기 총수요 구별 | [D-review.md](D-review.md) |
| E 구현 | 모든 실제 시도·실패·재시도 기록, stream/final usage 중복과 로그 재전송 구별, 누락은unknown | [E-review.md](E-review.md) |
| F 안종훈(가상) | 성능 양보 가능성과 환경 가치의 실제 결과, 원하는 결과를 미리 정하지 않음 | [F-review.md](F-review.md), [역할 근거](../../personas/F-Ahn-Jonghoon.md) |

각 기록은 이번 역할 사이에 실제 전달한 공개 방법 논점과 반론이다. native 계정 export·원래 메시지 시각·실제 전문가/사용자의 새 발언이라고 하지 않는다. 같은 메시지가 양쪽 파일에 중복될 수 있다. 비공개 추론·업무 배정은 보존 대상이 아니다.

F는 이번 사용자의 직접 발언을 근거로 한 가상 검토 역할이다. 사용자의 사생활·장비·예산·실제 추가 승인을 생성하지 않는다. F와의 가상 합의를 실제 사용자 의사로 바꾸지 않는다.

## 심사 전에 고정한 기준과 최종 평가

[새 고정 기준](rubric-v4.md)은 목표 변경에 따라 별도로 만들었다. 기존 v3 점수를 이월하거나 직접 향상/악화 비교하지 않는다. 모든 최종 평가는 같은 v4 통합 문서를 읽은 뒤 해당 역할 파일에 해시와 근거를 남겼다.

| 역할 | v4 최종 점수 | 의미 |
|---|---:|---|
| A | 78.75/100 | HCI 설계/실행 준비도 |
| B | 56.25/100 | 논문 설계/실증 준비도 |
| C | 51.25/100 | 모델·토큰·성과 기술 준비도 |
| D | 77.5/100 | 환경/운영 근거 준비도 |
| E | 50/100 | 새 목표의 실제 구현 준비도 |
| F | 취지 충실도100/100 | 사용자 견해를 문서에 반영한 정도. 실제 사용자 승인/연구 준비도 아님 |

F를 제외한 역할에 필요한 실제 모델·계측·UI 연결·최종 작업·독립 예비자료·새 분석/표본 근거는 미완료다. **전원100점에는 도달하지 않았다.** 가상 검토 점수는 연구의 효과·환경 개선·학술심사·게재 확률이 아니다. F와 A–E 점수를 평균 내지 않는다.

## 예상과 다른 결과도 연구 가능한가

가능성은 열려 있다. 실제 소비 증가, 토큰/J 불일치, 성과 비용, 정밀한 작은 효과 또는 해소되지 않은 불확실성을 정직하게 보고한다. 다만 결과 방향 자체가 기여/채택을 보장하지는 않는다. 공식 CHI 안내는 기여·독창성·근거·타당성과 투명성을 평가하며, ‘효과가 없으면 자동 채택’ 규칙으로 인용하지 않는다. ‘예상과 다른 결과’와 ‘결과 없는 계획을 완료 실증으로 보고’는 다른 상황이다. 사용자가 후자를 원했다고 해석하지 않는다.

- [CHI 2027 연구 품질 안내](https://chi2027.acm.org/guide-to-a-successful-submission/)
- [CHI 2027 심사 기준](https://chi2027.acm.org/authors/papers/papers-review-process/)

새 주 질문·토큰/환경 포함관계·분석 지위의 구체적 결정은 v4 본문이 우선한다. 현재 `confirmatory_allowed=false`이다.
