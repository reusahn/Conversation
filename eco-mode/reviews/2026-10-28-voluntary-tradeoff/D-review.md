# D · v4 자발적 성능 교환과 환경 영향 검토

2026-10-28. D는 가상 운영·환경 검토 관점이며 실제 CEO, 시설 운영자, 환경 인증자 또는 외부 심사자가 아니다. `protocol-v4-draft.md`, `F-Ahn-Jonghoon.md`, 심사 전에 고정한 `rubric-v4.md`를 읽었다. 실제 장비·계측·모델·참가자 자료는 확인하지 않았고 코드 검사도 실행하지 않았다. v3 점수를 v4로 이월하지 않는다.

## 핵심 판단

**품질 유지를 자원 절감의 필수 성공 조건에서 빼는 변경에 동의한다.** 사용자가 실제로 감수한 성능 교환과 자원 사용을 함께 밝히는 질문은 유지된다. 품질 저하·포기 증가가 있더라도 소비 감소가 관측되면 그 감소를 보고할 수 있다. 다만 같은 성과를 더 적은 자원으로 얻었다는 효율 주장, 사용자 의사에 부합한 교환이라는 해석, 장기 전체 수요 감소는 각각 추가 근거가 필요한 별도 주장이다.

환경 질문을 연구에서 삭제할 필요는 없다. 다음 세 수준으로 연결해야 한다.

| 근거 수준 | v4에서 다룰 내용 | 현재 상태와 주장 범위 |
|---|---|---|
| 직접 계측 | 사전 정의한 GPU 또는 시스템 입력 경계에서 세션 누적 J/Wh | 실제 계측 자료 없음. 토큰이나 실행시간으로 값을 채우지 않음 |
| 조건에 따른 환경 추정 | 직접 계측 경계와 일치하는 지역·시간·전력/냉각 자료를 이용한 탄소·물 영향 | 현재 자료 미확인으로 추정 불가. 위치·계수·출처·시각·시스템 경계와 불확실성을 확보한 경우에만 조건부 결과로 보고 |
| 아직 확인하지 않은 전체 영향 | 생태계 훼손 회피, 하드웨어 제조·물질 사용, 데이터센터/사회 전체 및 장기 수요 | 첫 실험으로 입증하지 않음. 미확인을 0 또는 환경 안전으로 표시하지 않음 |

사용자의 ‘자연을 아끼기 위한 선택이 실제로 도움이 되는가’는 **기대한 환경 이익과 확인 가능한 물리적·환경적 영향이 얼마나 일치하는가**로 살릴 수 있다. 환경을 위해 선택했다는 자기보고는 중요한 인식 결과이며, 계측값이나 환경 동기의 인과 매개 증명과 구별한다.

## 채택을 권고하는 구체적 명세

1. 세 수준의 환경 근거 표와 현재 `직접 계측 없음 / 탄소·물 추정 불가 / 생태 훼손 방지 전체 미확인`을 v4에 명시한다. 부재는 환경 질문의 포기가 아니라 검증 상태다.
2. 고정된 배정 작업·관측 기간의 소비 효과와 자유로운 장기사용의 전체 수요 효과를 구별한다. 첫 단계에서 기간 전체 반동을 해결했다고 하지 않는다.
3. 전체 배정 분모에서 세션 J·최종 성과·완료/포기·시간·수용 자기보고를 함께 보고한다. 완료자만 남기지 않으며 총량 감소를 생산성/동일성과 효율로 바꾸지 않는다.
4. 토큰 누락과 에너지 누락을 독립 상태로 관리한다. 단위·시각·epoch·센서/범위·raw 양끝·drain 참조·동시 타작업 여부와 미확인 사유를 보존한다.
