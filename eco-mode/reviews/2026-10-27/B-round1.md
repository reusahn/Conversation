# B 1라운드 보고 — v2.1 검토

가상 HCI 논문 포닥의 고정 기준에 따른 자문이다. 기준은 [기존 B 기록](../../personas/B.md)의 B1–B5와 동일하며 0·50·75·100% 배점 단계를 유지한다.
실행하지 않은 검사나 알려지지 않은 δ·표본 수·장비를 채워 만점을 주지 않는다.

## 판정

현재 문서 v2.1은 **62.5/100점**이다.
새 토론에서 분석·결측·계측 경계의 문서 수정안을 만들었으나, 아직 v3 구현과 실행 자료를 검토하지 않았으므로 이전 점수를 미리 올리지 않는다.

| 항목 | 점수 | 남은 증거 |
|---|---:|---|
| B1 독창성과 지식 기여 | 22.5/30 | 원문 대조 보완안을 본문에 반영하고, 결과가 바꿀 지식을 조합 나열보다 구체적으로 고정 |
| B2 질문과 인과설계 | 18.75/25 | 두 실제 운영 설정, UI·로그 실제 실행 확인 |

| B4 분석과 실패 처리 | 11.25/15 | 정확한 분석 규칙·결측 경계·주장 가족을 구현하고 예제 로그에 실행 |
| B5 범위와 수행 가능성 | 0/10 | 실제 사용할 모델·장비·비용·측정 경로 미확인 |
| 합계 | 62.5/100 | 실행 가능성 관문 확인 전 보류 |

B5의 고정 기준상 치명적 결격은 유지한다. 아이디어 자체의 무효를 뜻하지 않으며, 현재 단계에서 에너지 실증 준비 완료로 승인할 수 없다는 뜻이다.

## 실제 토론의 합의

- A와 최초 제출 확정 모드 하나를 최초 선택으로 삼고, 전체 배정자 분모를 유지하는 데 합의했다. genuine none과 로그 유실 unknown은 다르다.
- C와 공유 출력 제한 혼입 시 '추론 예산만의 효과'를 주장하지 않고 고정한 두 운영 설정에 대한 명명의 총효과로 한정하는 데 합의했다.
- D와 전용 백엔드 할당 세션 에너지에 생각시간 유휴와 취소 후 잔여 실행을 포함하되, 활성 호출 합계를 중복 가산하지 않는 데 합의했다.
- E와 참가자 1행 요약, 고정 과제 분모, 실제 하한·상한의 출처, 관측 누락 상태를 구분하는 데 합의했다.
- A와 네 확증 주장 가족, Bonferroni α=.0125, 에너지·모든 사전 품질 구간의 공동 통과 구조에 합의했다.
- 0분산을 품질 유지의 확실성으로 바꾸는 구현을 금지한다.
- S0는 절감이 양수인지로 통과시키지 않고 실제 제어·계측의 식별가능성으로 판정한다.

## v3의 정확한 분석 제안

최종 고정 과제집 K개를 모두에게 배정하고, 참가자별 첫 확정 예산·총 할당 세션 J·고정 분모 실패율을 1행으로 만든다.
반복 과제를 독립 참가자처럼 세지 않으며 주결론은 고정 과제집에 한정한다.
Eco–Low 및 Eco–Fast 각각에 대해 (1) 최초 선택 차이, (2) 에너지 감소와 품질 비열등성 공동주장을 만들어 총 네 확증 주장에 가족 α=.05를 배분한다.
각 주장 α=.0125이다.
공동주장은 ΔE의 단측 상한이 0보다 작고 모든 사전 품질 구간 ΔF_s의 단측 상한이 δ_s보다 작아야 통과한다.
각 품질 상한을 동시 신뢰구간이라고 부르지 않는다. 모든 조건을 함께 요구하는 하나의 IUT 주장이다.
bounded 선택·품질의 Hoeffding 상한은 보수적 준비/검증 방법으로 실행할 수 있다. 에너지에는 적용하지 않는다.
raw J 평균차에 대한 Welch 근사는 실제 파일럿의 왜도·영분산·소표본 검증 전 확증 실행으로 승인하지 않는다.
unknown을 none이나 실패로 바꾸지 않고, 유한 근거 상한이 없는 누락 에너지는 확증 주장을 차단한다.

## 지금 혼자 가능한 후속 작업

1. 참가자 없는 사건 재현·설정 불변성·카운터 조정과 분석 예제를 실행한다.
2. 결과표를 선택, 객관적 품질, 에너지, 실패·재시도·포기, 결측의 다섯 블록으로 고정한다.
3. δ·참가자 수는 가정별 민감도만 제시하고 실제 값으로 확정하지 않는다.
4. 본실험에는 필요한 자원과 기관 절차가 확인된 뒤 진입한다.
