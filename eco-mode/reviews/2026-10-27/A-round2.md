## 직접 확인한 범위

protocol-v3.md, analysis-appendix-v3.md, analysis_prepare.py, session_replay.py와 관련 검사 코드를 직접 읽었다.
초기 분석 코드의 빈 품질 구간은 실제로 numeric_quality_rule과 numeric_joint_rule을 True로 만드는 반례를 재현했다.
부모의 수정 뒤 필수 overall=전체 K, 배정 manifest·가명 참가자 ID·동일 설정 해시·동일 측정 경계 검사를 확인했다.
E·C가 제기한 제출 사건의 의미와 프로토콜 위반에 대한 선택/품질 격리도 최종 코드에서 확인했다.

A 실행환경에서 최종 코드에 다음을 독립 실행했다.

```text
python -m unittest test_research_tools -q
Ran 57 tests in 0.052s
OK
exit_code=0
```

이는 합성 사건·계측·분석 규칙의 제한된 검사이다.
UI, 실제 모델 예산 제어, 에너지 센서, 사람의 명명 반응 또는 품질 유지를 검증한 것이 아니다.

## 합의와 남은 판단

- 최초 선택의 현재 정의는 최초 UI 클릭이 아니라 서버에 수락·기록된 최초 확정 제출 모드이다. 제출하지 않은 UI 토글은 그 추정량에서 none이다.
- 진짜 무선택·관측된 미완료와 로그 유실을 분리하고, 전체 배정 분모를 유지한다.
- 선택/품질의 Hoeffding 경계는 모든 분산에서 일관되게 적용되어 전원 성공이 자동 비열등 통과가 되는 함정을 피한다. 독립성 가정과 높은 표본 요구는 남는다.
- raw J Welch 함수는 근사 준비 도구이다. 모든 입력에서 confirmatory_allowed=false라는 경계를 유지한다.
- δ 민감도나 가상 표본은 실제 허용폭·모집 가능성·검정력의 근거를 대신하지 않는다.
