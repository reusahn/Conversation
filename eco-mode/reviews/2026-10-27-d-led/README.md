D-dialogue는 작성자가 공개 토론 **요약**으로 표시한 문서다. 그대로 native 원문 전사라고 부르지 않는다.
업무배정 프롬프트·비공개추론·계정 전체 내보내기는 포함하지 않는다.

새 preflight나 실제 모델·센서·사람 실험은 하지 않았다. 기존 계수의 의미 혼동은 후속에 수정했다.
과제 간 모드변경, 과제 내 전환/상향/재제출, 같은 요청의 추가 실행 attempt를 분리했다.
E는 수정 후 전체62/62, B는 관련8/8을 독립 확인했다. B는 수정 전57 전체도 이번에 검증했다.
B를 수정 후62 전체 독립재현자로 표시하지 않는다.
