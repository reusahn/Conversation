# A/B 공개 가상 교차 토론 — 명칭의 비교와 설문 반응성

2026-10-28. A(HCI 교수), B(HCI 논문 포닥)는 실제 인물이나 외부 심사자가 아니라 한 도우미가 적용한 가상 검토 관점이다. 새 연구 제안이며 과거 발언의 복원 원문이 아니다. 장비 질문은 보류했다. 실제 참가자·모델·계측·새 검사를 실행하지 않았으며 기존 점수나 활성 분석 코드를 바꾸지 않는다.

검토 범위: protocol-v3.md, task-evaluation-spec.md, quality-design-candidate.md 및 A/B 고정 기준의 이전 평가. 문서로 해결 가능한 두 문제를 아래와 같이 구체화한다.

## 라운드 1 — 사용 전 기대를 물으면 이름 효과만 남는가

**A:** “기존 계획은 사용 전 품질 기대도 측정하려 했습니다. 그런데 이름을 보여주고 ‘얼마나 품질이 좋을까요?’라고 물으면 참가자가 원래보다 모드의 품질 차이를 더 의식할 수 있습니다. 그 설문이 실제 선택에 영향을 주는 추가 개입이 됩니다.”

**B:** “설문을 세 군에서 똑같이 해도 무설문 환경으로 일반화할 수 있다는 뜻은 아닙니다. 우리가 원하는 첫 논문의 질문은 자연스러운 명칭 선택의 총효과에 가깝습니다. 첫 선택 전에는 모드 품질·속도·환경을 평가하게 하지 맙시다.”

**A:** “그러면 기대 품질이 매개한다는 분석은 포기해야 합니다. 실험 뒤에 물은 기대는 사용 전 실제 기대를 관측한 것이 아닙니다. 이름의 기억·이해·환경 연상·체감 품질·만족도는 전체 작업이 잠긴 뒤 보조적으로 물을 수 있습니다.”

**B:** “동의합니다. 사후 환경 태도나 사후 품질 인식을 기저 특성이라고 부르거나 주분석의 공변량으로 보정하지 않겠습니다. 주효과는 전체 무작위 배정자의 원배정 분석으로 유지하고, 사후 설문은 해석을 돕는 탐색 자료라고 쓰겠습니다.”

### 결정 1 — 본 실험의 설문 순서 후보

1. 명칭 노출 전에는 동의, 필수 자격·작업 관련 숙련도와 공통 사용법만 제공한다. 환경 중요도·추론 모드 선호·기대 품질을 묻는 항목은 첫 행동의 선행 측정에서 제거한다. 사전 문항을 추가해야 한다면 그 반응성이 없는 것으로 가정하지 말고 프로토콜과 일반화 범위를 다시 고정한다.
2. 무작위 배정된 Low/Fast/Eco를 보여준 뒤 첫 선택 전 또는 과제 사이에 기대·환경 인식 설문을 끼워 넣지 않는다.
3. 모든 배정 작업의 입력·최종 산출물이 잠긴 뒤 이름 기억, 이름이 뜻한다고 생각한 내용, 체감 품질, 만족도, 연구 목적 추측을 보조적으로 수집할 수 있다. 과제 수행 에너지 구간과 사후 설문 구간을 별도로 표시하고 기존 backend drain 비용을 지우지 않는다.
4. 사후 측정은 실제 사전 기대, 무오염 환경 성향, 인과 매개, 정확한 사전 신념으로 해석하지 않는다. 사후 이름 기억 실패·목적 간파를 이유로 참가자를 주분석에서 제외하지 않는다.
5. 사전 기대 자체를 확인하려면 별도 독립 표본/별도 연구의 명칭 인식 자료로 취급한다. 지금 참가자를 동원하거나 별도 연구를 필수 확장하지 않는다. 별도 인식 자료로 본 실험 참가자의 매개효과를 입증하지 않는다.

이것은 측정 반응성을 줄이려는 설계 선택이며 실제 반응성이 얼마나 줄었는지는 아직 관측하지 않았다.

## 라운드 2 — Eco–Fast 비교가 무엇을 알려주는가

**B:** “Eco와 Fast가 모두 Low보다 잘 선택되어도 환경을 생각해서 선택한 것인지, 긍정적인 이름이라서 선택한 것인지는 남습니다. Eco–Fast가 유의하다고 환경 동기만의 효과가 입증되는 것도 아닙니다.”

**A:** “그 차이는 약점만은 아닙니다. 첫 논문은 실제 사용할 세 이름 중 무엇이 선택과 작업 성과에 어떤 총효과를 주는지 답하도록 좁히면 됩니다. 의미가 완전히 맞춰진 단어를 더 넣어 심리기제를 분리하려 하면 첫 연구가 커집니다.”

**B:** “속도·에너지·품질 설명을 조건별로 붙이는 것도 금지해야 합니다. Eco에만 잎 아이콘이나 ‘지속가능한 선택’을 붙이면 명칭의 비교가 아닙니다. 반대로 공통 설명에 ‘이것은 친환경 모드’라고 쓰면 세 군을 같은 환경 메시지로 오염시킵니다.”

**A:** “따라서 라벨 문구만 다르게 하고 나머지 공통 정보를 고정합니다. 다만 Eco나 Fast 자체가 무엇을 보장하는지 불명확한 문제는 기술 자문과 별도로 확인해야 합니다. 속도·환경 절감을 검증하지 않은 수치나 보증 문구를 보태지 않고, 관측된 효과와 실제 보증 범위를 구분하죠.”

### 결정 2 — 처치와 주장 경계 후보

| 요소 | 동결 원칙 | 해석 |
|---|---|---|
| 낮은 모드의 표시 이름 | Low / Fast / Eco 중 배정된 하나만 사용 | 세 구체적 명칭의 총효과 |
| 높은 모드 표시 | 모든 조건에서 동일 High | 동일한 선택지 구성 |
| 설명·위치·색·크기·아이콘·기본값 | 공통 내용과 레이아웃의 정확한 문구·버전을 보존. 차이는 저모드 이름에 한정. 공통 기본값은 기존처럼 없음 | 추가 설득·시각적 강조를 함께 조작하지 않음 |
| 속도·품질·에너지 정보 | 세 군에서 같은 근거·단위·문구·제시시점 사용. Eco 전용 환경 호소나 Fast 전용 시간 보증을 추가하지 않음 | 공통 정보가 있는 바로 그 환경에 조건부인 명칭 효과 |
| 모집·사용법·목적 설명 | 적용 절차가 요구하는 정보를 충족하면서 세 군에 공통 문구 제공. 환경 절감 목표를 참가자 과제의 성공기준으로 요구하지 않음. 실제 문구는 동결 전 확정 | 연구자의 선호 행동을 지시한 효과와 명칭 효과의 혼합을 줄이는 준비 원칙 |
| Eco–Low | 기존 Low를 Eco로 교체한 총효과 | 의미·정서·품질 인상 차이를 모두 포함 |
| Eco–Fast | 환경을 연상시키는 명칭과 속도를 연상시키는 명칭의 비교 | 환경 동기 단독 효과, 전반적 긍정성의 통제, 모든 친환경 라벨 일반효과를 보증하지 않음 |
| 사후 기억·이해 응답 | 보조 결과. 명칭 기억 실패자의 주분석 사후 제외 금지 | 주효과를 사후 응답에 조건부로 왜곡하지 않음 |

추가 Light/Standard 조건이나 환경 태도 교차요인을 이번 첫 연구에 넣지 않는다. 세 명칭 중 어느 것이 어떤 과제 조건에서 유리하거나 불리한지라는 질문을 유지한다.

## 라운드 3 — 고정 점수와 다음 수정

**B:** “이 두 결정은 설계 해석을 분명히 하지만, 이미 A2와 A4가 만점인 상태에서 문구를 더 썼다고 A 전체를 100점으로 올릴 수 없습니다. 기존 감점인 최종 과제·실용 허용폭·독립 자료·실행 가능성은 남아 있습니다.”

**A:** “동의합니다. 장비 질문 없이도 이 두 보완은 채택할 수 있습니다. 다만 A3·A5의 근거가 생긴 것은 아니므로 A92를 유지하고 B의 기존 완료62.5도 새 실행 근거 없이 올리지 않겠습니다. 앞으로는 새 문서 수가 아니라 각 고정 기준의 실제 결손을 해결했는지로 재심사합시다.”

## 부모가 통합할 구체적 수정

- protocol-v3의 후속 설계 부록에 ‘첫 행동 전 기대 품질·환경 설문 없음, 사후 설문은 보조이며 사후 제외·매개 입증·공변량 보정에 사용하지 않음’을 추가한다.
- UI 명세에 조건별 차이의 허용 목록(저모드 표시 문자열 하나)과 공통 문구·자산의 동일성을 기록한다. 공통 정보가 무엇인지 확정 전에는 ‘명칭 외 모두 동일’을 구현 완료로 표시하지 않는다.
- 연구 주장에 Eco–Fast가 환경 동기 단독의 인과효과를 식별하지 않는다는 제한을 유지한다. 세 조건을 그대로 두며 별도 메커니즘 실험을 필수로 추가하지 않는다.
- 실제 참가자·장비·계측 없이 가능한 설계 개선으로 보고한다. 설계 만점·실험 준비 완료·효과 입증은 선언하지 않는다. `confirmatory_allowed=false`를 유지한다.

## 기존 선행 대조의 적용

부모가 재확인한 Klesel/Messer CHI2026 연구(arXiv:2603.23075v1)의 동일 실제 backend·가상 LLM/SLM, 성능 및 에너지 등급 조작은 기존 `reviews/2026-10-27/B-source-comparison.md`에도 기록되어 있다. 이번에 동일 backend 설계를 새 차별성으로 발견했다고 보고하지 않는다. 이번 진전은 그 대조를 명칭만의 자극 문구와 첫 행동 전 설문 제거라는 결정에 연결한 것이다. 실제 두 추론 예산, Low/Fast/Eco 표시 이름만의 비교, 객관 최종품질과 전체 세션 J 및 과제 조건의 결합은 차별성 후보이며 최초 연구라는 주장을 확정하지 않는다. A/B 담당은 해당 외부 원문을 직접 열람하지 않았고 부모의 확인 내용과 기존 기록을 인계받아 반영했다.

## C/D/E와의 공개 교환

**C/D/E 질문:** “공통 안내를 ‘두 모드는 허용되는 추론 계산량이 다릅니다. 필요하면 모드를 바꾸거나 다시 질문할 수 있습니다’로 고정하고 절감·속도 보장을 제거하면 이름의 의미를 약화합니까? 기대·환경 인식은 사후 또는 별도 파일럿으로 옮겨도 원래 질문을 보존합니까?”

**A/B 답변:** “이름만 다른 비교에 적합합니다. 다만 공통 계산량 안내가 있는 환경의 명칭 총효과로 해석하고 안내 없는 UI까지 일반화하지 않습니다. 고/저 중 어떤 쪽이 어떤 예산인지 추가 수수께끼를 만들지 않도록 모드–예산의 공통 대응관계를 명확히 동결하세요. Eco/Fast를 정답인 선택으로 지시하지 않습니다. 사전 설문 제거 뒤에도 명칭의 선택 총효과라는 원래 질문은 보존됩니다. 사후 설문은 기저 기대나 매개 증거로 쓰지 않고, 필요할 때 별도 지각 파일럿으로 기대를 확인하되 본실험 참가자의 매개효과로 전이하지 않습니다. 별도 파일럿을 지금 필수 확장으로 추가하지 않습니다.”

실제 문헌 검색·외부 원문 직접 대조는 이번 A/B 담당이 수행하지 않았다. 위의 두 결정은 기존 설계의 측정 순서·추정대상에 대한 방법 제안이며 검증된 현상이나 확정 novelty로 인용하지 않는다.

# C·D·E의 설계 보완 제안

2026-10-28. C(AI), D(운영), E(개발)는 가상 자문 관점이며 실제 외부 전문가의 평가가 아니다. 이번 문서는 장비 질문을 보류한 상태에서 작성한 공개용 제안 대화다. 실제 모델·센서·참가자·검사 실행 또는 새로운 효과 결과는 없다. protocol-v3와 quality-design-candidate를 교체하지 않는 설계 보완 후보이며 기존 점수를 올리지 않는다.

## 쟁점 1: Eco라는 이름과 절감 보장의 구분

**D:** “Eco가 저예산의 이름이라고 해서 과제 완료까지 전기가 덜 든다는 뜻은 아닙니다. 그렇다고 낮은 설정의 절감을 먼저 증명해야만 연구를 시작하도록 정하면, 오히려 절감에 실패하는 경우를 제외하게 됩니다.”

**C:** “기술 관문은 실제 두 예산 적용과 비교 가능한 기록입니다. 그 관문과 이름의 진실성·설명 정책을 분리합시다. 연구 화면에 ‘환경을 보호합니다’, ‘항상 전기를 절약합니다’, ‘더 빠릅니다’ 같은 검증되지 않은 성과 보장을 붙이지 않겠습니다.”

**E:** “화면 공통 안내의 후보를 ‘두 모드는 응답을 생성할 때 허용되는 추론 계산량이 다릅니다. 필요하면 모드를 바꾸거나 다시 질문할 수 있습니다’로 고정할 수 있습니다. 세 집단 간 낮은 설정 이름 Low/Fast/Eco만 바꾸고, High와 나머지 문구·아이콘·색·배치는 같습니다.”

**C:** “이 후보 문구도 실제 두 예산 적용이 확인되어야 실행 화면에 쓸 수 있습니다. 단순히 짧게 답하라는 프롬프트 차이를 이 설명에 끼워 넣으면 안 됩니다. 지금은 문구 후보만 정합니다.”

**D:** “Low가 더 소비하더라도 결과를 보존합니다. 이름의 적합성과 작업 전체 절감의 불일치가 연구 결과가 될 수 있습니다. Eco가 환경 효과를 보장한다고 참가자가 이해하는지는 별도 관찰 대상이지 연구자의 보장 문구가 아닙니다.”

**E:** “실험 종료 뒤에는 낮은·높은 두 실제 설정은 유지되었고 세 집단 사이에는 낮은 설정의 표시 이름만 달랐다는 사실, Eco 이름만으로 절감이 보장되지 않는다는 사실을 설명하는 문안을 준비하겠습니다. 실제 적용할 설명·동의·사후설명의 적합성은 기존 사람 연구 준비 단계에서 검토하며, 이 문서로 승인됐다고 표시하지 않겠습니다.”

**C:** “공통 안내가 있는 상황의 이름 효과가 추정 대상입니다. 설명을 없앤 상용 화면이나 자동 선택 서비스 전체로 일반화하지 않습니다. Eco–Fast 차이도 환경 동기만의 효과로 해석하지 않습니다.”

### 반영할 명세

- 독립 변수는 낮은 모드의 표시 이름 하나다. 공통 안내·높은 모드·허용된 기능의 버전/화면을 함께 보존한다.
- 이름에 환경·속도 성과 보장 문구나 집단별 설명을 추가하지 않는다.
- 공통 안내는 양 모드의 실제 제어 의미와 기능을 중립적으로 설명하는 후보이며 최종 UI/이해도 점검 전에 확정하지 않는다.
- Low의 절감 부호를 기술 관문으로 쓰지 않는다. 이름의 행동 효과와 실제 총소비 효과를 각각 평가한다.
- 참가자가 환경 의미를 떠올렸다는 응답만으로 환경 동기의 인과 매개를 확정하지 않는다. 기대·해석 질문의 시점은 A/B 검토와 통합해 정한다.

## 쟁점 2: 상대 품질 유지가 사용 가치까지 보장하지 않음

**D:** “예를 들어 양쪽의 과제 성공률이 모두 매우 낮다면, 차이가 작고 에너지가 줄어도 실제로 쓸 만한 AI라고 추천할 수 없습니다. 상대 비교와 활용 판단의 문구를 분리해야 합니다.”

**C:** “기존 비열등성은 허용한 추가 실패 범위의 상대 비교입니다. 결과에 맞춰 절대 성공률 문턱을 새로 넣거나 허용폭을 넓히지는 않겠습니다. 절대 수용성 문제는 기존 후보 문서가 이미 미해결 관문으로 남겼으므로 해결됐다고 표시하지 않습니다.”

**E:** “결과 표에는 각 arm의 전체 배정 과제 수, 관측 성공·실패·unknown을 함께 둡니다. 상대 차이만 보여주지 않습니다. unknown을 실패 또는 성공으로 바꿔 원시 성공률을 꾸미지 않고 관측 현황과 보수적 분석 경계를 분리합니다.”

**D:** “실제 절대수용 기준을 아직 정하지 않았다면, 실용적 배포 권고까지 쓰지 않는다는 문구를 지금 고정할 수 있습니다. 연구 결과를 숨기지 않고 주장 범위를 줄이는 결정입니다.”

**C:** “따라서 공동 검정이 통과해도 ‘정한 과제·측정 경계에서, 사전 상대 품질 기준을 충족하며 세션 에너지가 감소했다’까지만 말합니다. ‘충분히 유용하다’, ‘환경을 보호한다’, ‘모든 사용자에게 권장한다’는 별도 근거가 필요합니다. 실제 판정 자체도 아직 수행하지 않았습니다.”

### 결과별 허용 문구 후보

| 관찰·판정 상태 | 허용할 해석 | 남는 한계 |
|---|---|---|
| 에너지 감소와 모든 사전 상대 품질 기준 충족 | 선택한 과제·사용자·측정 범위에서 상대 품질 제한 아래 세션 에너지 감소 | 절대 사용 적합성·일반화·환경 영향은 별도 |
| 에너지 감소, 품질 기준 미충족 | 에너지 감소와 품질 유지의 공동 기준은 충족하지 못함 | 저에너지만으로 유용한 절약이라고 결론내리지 않음 |
| 품질 기준 충족, 에너지 감소 미확인 | 상대 품질 조건만 충족 | 유의하지 않은 에너지 차이를 동등함으로 부르지 않음 |
| 어느 쪽이든 자료·검정력·유효성 불충분 | 해당 주장은 미해결 | 무효과·안전·동등성의 증명 아님 |

이 표는 새로운 검정이나 유리한 통과 경로를 추가하지 않는 주장 표현 규칙이다. 기존 절대수용성 채택 여부·근거 결정, 실제 δ/p_min/최종 과제/표본 및 실행 근거는 그대로 미완료다. 실제 검정 결과는 아직 없다.

## 점수와 다음 설계 작업

기존 완료 점수 A92, B62.5, C설계100, D73, E설계97/실행50을 유지한다. 이번 제안으로 실측·실행 증거 점수를 올리지 않는다. 장비 정보 요청 없이 화면 문구·측정 질문 시점·주장 표현을 다음 통합 설계에서 결정할 수 있다. `confirmatory_allowed=false`를 유지한다.

## A/B와의 공개 교환

아래는 이번 검토 중 역할별 검토자가 보낸 공개용 메시지의 텍스트다. 외부 전문가 발언이나 사람 연구 자료가 아니다.

**C/D/E → A/B 질문:** “Eco–Fast 비교가 환경 심리 원인을 특정하지 않는다는 기존 한계를 유지하면서, 공통 안내를 ‘두 모드는 허용되는 추론 계산량이 다릅니다. 필요하면 모드를 바꾸거나 다시 질문할 수 있습니다’로 고정하고 절감/속도 보장 문구를 제거하는 안을 검토 중입니다. 이 안내가 명칭 조작을 약화하거나 어떤 구성타당도 문제를 남기나요? 환경 인식·품질 기대는 사후/별도 파일럿으로 옮길 경우 원래 질문을 보존할 수 있는지도 답해주세요.”

**A/B → C/D/E 답변:** “제안한 공통 안내는 이름만 달라지는 비교에 적합합니다. 다만 공통 계산량 안내가 있는 상황의 명칭 총효과로 해석하며, 안내 없는 UI까지 일반화하지 않습니다. 고/저 중 어떤 쪽이 어떤 예산인지 참가자에게 숨겨 추가 수수께끼를 만들지 않도록 공통 설명의 대응관계는 명확히 동결하세요. Eco/Fast를 정답인 선택으로 지시하거나 속도/절감을 보장하는 문구는 보태지 않습니다. 본실험 첫 행동 전 기대품질·환경 설문을 제거하면 원래 선택 효과 질문은 유지됩니다. 사후 설문은 기저 기대나 매개 증거로 쓰지 않고, 필요하면 독립 지각 파일럿으로 사전 기대를 별도 확인하되 그 참가자 반응을 본실험 매개로 전이하지 않습니다. 독립 파일럿은 지금 반드시 실행할 확장 조건으로 추가하지 않습니다.”

**C/D/E의 반영:** 공통 안내에 계산량 차이를 말하는 것에 더해 각 표시 이름이 어느 한도에 연결되는지 같은 형식으로 보여주는 안을 통합안에 제안한다. 예: 낮은 카드 Low/Fast/Eco 아래의 공통 보조 설명 ‘낮은 추론 한도’, High 아래 ‘높은 추론 한도’. 이 매핑은 세 집단에 동일하게 제시하고 이름만 바꾼다. 이런 명시적 매핑 아래에서도 이름이 추가로 미치는 효과가 대상이며, 모드 의미가 숨겨진 화면의 효과로 확대하지 않는다. 최종 표현은 통합 문서에서 한 버전으로 고정하고 UI 확인 전 실제 적용 완료라고 부르지 않는다.

# 명칭 실험 설계 보완 — 채택한 설계 결정

2026-10-28. protocol-v3의 연구 질문·세 조건·통계 분석은 유지한다. 이 문서는 이번 가상 A–E 토론에서 채택한 측정 순서·자극·주장 표현 보완이다. 실제 UI, 모델, 계측, 참가자 자료나 새 검사 결과는 없다. 장비 질문은 현재 설계 토론의 선행조건으로 두지 않는다. `confirmatory_allowed=false`를 유지한다.

## 1. 이번에 결정한 것과 아직 검증하지 않은 것

| 항목 | 이번 결정 | 미완료 범위 |
|---|---|---|
| 사전 설문 | 본실험의 명칭 노출 뒤 첫 선택 전·과제 사이에 기대품질·환경 의미·선호 설문을 넣지 않는다. 행동 전 환경 태도 질문도 제외한다. | 실제 화면·이해도·측정 반응성의 크기 |
| 사후 설문 | 전체 산출물 잠금 뒤 이름 기억·자유로운 의미 설명·체감품질·만족도·목적 추측을 보조 자료로 받는다. 자유응답을 환경 연상 선택문항보다 앞에 둔다. | 최종 문구·번역·척도 동결과 사용성 점검 |
| 사전 기대 | 첫 본실험의 필수 결과에서 제외한다. 필요하다면 독립 지각 연구로 분리한다. | 현재 참가자 모집이나 추가 연구를 시작한 것이 아님 |
| 추정 대상 | 아래 공통 안내가 제공되는 상황에서 세 구체적 이름을 교체한 총효과이다. | 모든 친환경 라벨·순수 환경 동기·매개효과로 일반화 불가 |
| 상대 품질 | 기존 비열등성 규칙을 유지하며 arm별 절대 성공·실패·unknown을 함께 보고한다. | 실제 허용폭과 절대 수용성 필요 여부·기준·근거는 여전히 미정 |

사후 설문 응답은 사용 전 기대의 직접 관측이 아니며, 사후 기억 실패·목적 간파를 이유로 주분석에서 제외하지 않는다. 사후 태도·체감품질로 무작위 명칭의 총효과를 보정하거나 인과 매개를 확정하지 않는다.

## 2. 화면 자극 초안

참가자용 공통 안내의 작업 초안:

> 두 모드는 응답을 생성할 때 허용되는 추론 계산량이 다릅니다. 과제에 사용할 모드를 선택하세요. 진행 중 모드를 바꾸거나 다시 질문할 수 있습니다.

| 무작위 집단 | 낮은 예산 버튼 | 높은 예산 버튼 | 공통 안내 |
|---|---|---|---|
| A | Low | High | 위와 동일 |
| B | Fast | High | 위와 동일 |
| C | Eco | High | 위와 동일 |

저예산 표시 문자열만 바꾼다. 기본 선택 없음, 두 버튼의 자리·크기·색·아이콘·스타일·설명·가격·이용한도와 높은 설정의 High 표시는 집단 간 동일하게 유지한다. Eco의 글자 수 차이가 줄바꿈·버튼 폭·강조 차이를 만들지 않도록 고정 레이아웃을 준비한다. 참가자가 한 세션에서 다른 집단 명칭을 보지 않게 한다. 실제 구현 검사는 아직 없다.

이 초안에 ‘친환경’, ‘더 빠름’, ‘품질 동일’, 절감 수치 또는 성능 별점을 덧붙이지 않는다. 모드 자체의 이름이 만드는 추론은 관찰 대상이며 연구자가 성과를 보증하는 문구와 구별한다. 공통 안내도 추정 대상의 일부이므로 안내 없는 서비스에 그대로 일반화하지 않는다. 실제 두 추론 예산 적용 확인 전 이 안내가 구현된 사실이라고 하지 않는다. 실제 동의·목적 설명·사후 설명 문구는 사람 연구 준비에서 검토·동결하며, 이번 문서는 그 승인을 대신하지 않는다.

사후 설명에는 ‘낮은·높은 두 실제 설정은 유지되며, 세 집단 사이에서 낮은 설정의 표시 이름만 달랐다’고 명확히 쓴다. 두 모드의 실제 설정이 서로 같았다고 설명하지 않는다. Eco 이름만으로 총에너지 절감이나 환경 개선을 보장하지 않는다.

## 3. 세션 순서와 에너지 경계

1. 공통 동의·자격·과제 관련 숙련도·사용법을 제공한다. 환경 행동의 바람직함을 과제 성공기준으로 요구하지 않는다.
2. 최초 명칭 노출 전에 기존 참가자 단위 배정 규칙을 적용한다. 실제 명칭 노출 직전부터 세션 계측을 시작한다.
3. 모드 선택·작업·재요청·전환을 수행한다. 과제 사이 인식 설문을 넣지 않는다.
4. 기존 완료·포기·기한 규칙에 따라 입력과 산출물을 잠근다. 잠금 후 응답은 최종 산출물에 반영하지 않는다.
5. 기존 backend-drained 증거까지 계측한다. 사후 설문 때문에 임의로 GPU 할당을 연장하지 않는다. 잠금 후 설문과 실제 drain이 겹친다면 원래 drain 에너지를 빼거나 두 번 세지 않는다.
6. 사후 설문과 사후 설명을 보조 절차로 수행한다. 설문 결과로 주분석 표본을 사후 선별하지 않는다.

## 4. 결과 해석 규칙

| 결과 | 보고할 결론 |
|---|---|
| Eco 선택 증가만 확인 | 최초 저예산 제출 선택이 증가했다. 에너지 절감 여부는 별도이다. |
| 세션 에너지 감소·필수 상대 품질 기준 모두 충족 | 정한 과제·사용자·측정 경계에서 사전 상대 품질 제한 아래 에너지가 감소했다. 절대 사용 적합성이나 환경 전체 개선은 별도이다. |
| 에너지 감소·품질 기준 미충족 | 공동 성공 기준을 충족하지 못했다. 비열등성 미확인은 곧 품질 악화의 확증이라는 뜻도 아니다. |
| 품질 기준 충족·에너지 감소 미확인 | 에너지 감소는 확인하지 못했다. 차이 없음·동등성을 확증했다고 하지 않는다. |
| 큰 unknown·유효성 결함·검정력 부족 | 해당 주장을 미해결로 남긴다. 실패·누락을 0으로 대체하거나 유리한 표본만 남기지 않는다. |

각 arm에서 전체 배정 분모 대비 관측 성공·실패·unknown 수와 비율을 함께 보고한다. unknown이 있으면 확인된 성공 비율과 잠재 성공률의 단순 식별 범위를 구별한다. 이 범위를 신뢰구간으로 부르지 않는다. 기존 확증 규칙·오류 배분·품질 허용폭을 이번에 임의 교체하지 않는다. 절대 수용 기준 결정은 여전히 미충족이며, 실제 본실험 진입·실용 배포 권고를 선언하지 않는다.

## 5. 문헌 재확인과 차별성 후보

[Klesel & Messer, CHI 2026](https://arxiv.org/html/2603.23075v1)의 §4.1·§4.3을 다시 확인했다. 두 표시 선택지의 backend는 동일 GPT-4o mini였고 성능 별점과 에너지 등급으로 기대를 조작했다. 기존 B-source-comparison에 있던 내용의 재확인이며 이번 새 발견이 아니다. 따라서 ‘같은 모델의 환경 프레이밍’ 자체는 새 기여가 아니다.

이번 계획의 차별성 후보는 **실제 두 추론 설정에 대한 명칭만 바꾸고, 객관적 최종 과제 성과와 재시도·전환·유휴·drain을 포함한 세션 에너지를 함께 비교하는 것**이다. 이 결합이 분야 최초이거나 충분한 기여라는 판단은 아직 미완료다.

[Levav & Fitzsimons, 2006, 저자 소속기관의 연구 요약](https://business.columbia.edu/faculty/research/when-questions-change-behavior-role-ease-representation)은 행동 의도를 묻는 질문 자체가 후속 행동을 바꿀 수 있는 실험을 보고한다. 이것은 이 연구의 품질기대 문항이 동일한 효과를 낸다는 직접 증거는 아니다. 위 설문 순서 결정은 측정이 행동에 개입할 위험을 줄이려는 방법상의 판단이다.

## 6. 평가

기존 완료 점수 A92, B62.5, C설계100, D73, E설계97/실행50을 유지한다. C의 설계 점수는 실행·효과 인증이 아니다. 이번 보완으로 이미 충족한 해석 명세가 분명해졌지만, 최종 과제·실용 허용폭·타당화·실측·실제 UI 연결·표본 근거의 결손이 사라진 것은 아니다. 기준을 바꾸거나 점수 항목을 재정의해 전원100으로 표시하지 않는다.

이번 완료물은 가상 역할 공개 토론과 문서 설계 결정이다. 새 코드 검사·모델 실행·센서 계측·사람 실험은 수행하지 않았다. 현재 작업을 마친 뒤 자율적인 배경 토론이나 자동 수집이 계속된다고 약속하지 않는다.
