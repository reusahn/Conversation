# 과제·채점 검토와 필요한 다음 근거

2026-10-28. 사용자가 전원100까지 연구/가상 역할 토론을 계속하고 필요한 것을 알려 달라고 요청했다. 장비 질문은 보류했다. 이번 결과는 문서 설계와 신뢰된 개발 함수 실행이며 실제 모델·센서·사람 실험이 아니다.

## 이번에 해결한 문제

1. **low 불충분은 high 유효의 근거가 아니다.** 독립 벤치에서 low 기준 충족 / high에서 기준 충족 확인 / 둘 다 기준 미달 / 미분류를 구별하는 [분류 보완](../../research/task-strata-correction-v0.1.md)을 작성했다. 실제 분류는 미실행이다.
2. **정답도 오채점할 수 있다.** 입력용 배열 요구를 정상 readonly 출력에도 적용한 거짓 실패를 실제 재현하고 수정했다. null 옵션이 runner 밖 예외로 탈출하는 문제도 개발 중 수정했다. 수리된 것은 개발 scorer이며 사람의 품질 유지가 입증된 것이 아니다.
3. **개발 예제와 본실험 자료를 분리했다.** 정수/ASCII/경계/수동 완성의 [개발 계약](../../research/development-task-contract-v0.1.md), [운영·사후 채점 경계](../../research/scoring-boundary-v0.1.md), [Methods 후보](../../research/development-evaluation-methods.md)를 마련했다.

## 필요한 것

[필요한 결정과 단계별 자료](../../research/requirements-for-next-evidence.md)에 정리했다. 지금 첫 결정은 코드 수정 작업을 첫 연구대상으로 삼을지이다. 실제 계측 장비/서버 접근과 시간·지출 상한은 기술 실행 직전에, 사람 참가자는 이름의 행동 효과를 확인할 단계에서 필요하다. 지금 자기 컴퓨터 사양·장비 구매·참가자 모집을 요구하지 않는다.
