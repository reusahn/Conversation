# 이어가기

## 사용자의 현재 요청

이 연구의 사용자–도우미 대화와 가상 페르소나 대화를 reusahn/Conversation에 저장하고 각 턴마다 갱신한다.
A–E가 고정 심사기준으로 토론하고 모두 100점을 줄 때까지 개선하길 원한다.
해커톤은 제외한다. 혼자 연구하며 참가자는 필요할 때 검토한다.

## 연구 질문

동일한 낮은 추론 설정의 Low/Fast/Eco 명명이 선택을 바꾸고, 품질을 유지하면서 실패·재시도까지 포함한 전체 에너지를 줄이는가?
환경 파괴 방지는 직접 측정한 결과가 아니며 에너지 결과에서 자동 도출하지 않는다.

## 완료

- 현재 접근 가능한 대화와 자문 기록의 전사·복원 요약을 구분해 보존.
- 고정 기준과 완료된 버전별 점수 보존.
- 연구안 v2.1 및 출처·검정력 민감도 시나리오 작성.
- 합성 엔지니어링 검사 42/42, 실제 모델·센서·사람 결과는 아님.
- 사용자 지정 GitHub 저장소에 기록. 현재 저장소는 공개이다.

만점이나 후속 점수를 추정하지 않는다. 새 실행/심사 결과가 있으면 버전과 출처를 붙여 추가한다.

## 다음 작업

정보가 없을 때도 문헌·UI·로그 설계는 진행할 수 있다.

## 다음 턴 저장 순서

1. 해당 턴 사용자 메시지와 사용자에게 보이는 도우미 답변, 완료된 자문·검증·수정 사항을 추가한다.
2. 원문과 복원 요약을 구분한다. 접근하지 못한 과거 내용은 완전하다고 표시하지 않는다.
3. 현재 브랜치를 다시 읽어 다른 대화의 변경을 보존한다.
4. 관련 파일을 실제 커밋하고 원격 읽기로 확인한다.
5. 응답에 저장 위치를 제공한다. 실패 시 성공했다고 말하지 않는다.

이 저장소나 현재 연결은 다른 ChatGPT 채팅의 새 메시지를 자동 수집하지 않는다.
사용자에게 보이는 기록만 보존하고 비공개 추론·시스템 지시·관계없는 개인 정보는 기록하지 않는다.
