# ContextLens
**반복은 줄이고, 선택권은 넓히다.**

**문제**
같은 짧은 영상이 계정, 화면 크롭, 자막, 편집을 달리해 반복적으로 나타납니다. 이용자는 익숙한 장면을 계속 접하면서도 반복 노출을 조절하기 어렵습니다. 비슷한 영상을 일괄적으로 숨기면 새로운 해설이나 후속 장면까지 놓칠 수 있습니다.

**제안**
ContextLens는 반복되는 장면을 인식하고, 개인에게 몇 번 나타났는지 보여주는 영상 필터입니다. 기본 설정에서는 같은 장면이 세 번째 나타날 때 게시물을 블러 처리합니다. 이용자는 적용 횟수를 조절하고, 가려진 영상을 언제든 다시 열 수 있습니다.

핵심은 **반복 속에서 달라진 부분을 남기는 것**입니다. 추가된 장면은 유지하고, 향후 Meta 모델을 연결해 자막과 해설의 차이도 비교할 계획입니다. 판단이 불확실한 영상은 그대로 표시합니다.

**해커톤 프로토타입**
공개 라이선스 영상 클립 5개와 편집 버전을 활용한 영어 메신저 형태의 웹앱입니다. 현재 영상 매칭, 반복 노출 횟수 표시, 블러 기준 조절, 추가 구간 재생, 파일 업로드, 호환되는 직접 영상 링크 가져오기가 구현되어 있습니다. 실제 Instagram이나 Messenger에는 연결되지 않았습니다.

**Meta 모델 활용 계획**
Muse Spark를 활용해 영상에 붙은 텍스트와 해설을 비교하고, 제공된 자료에 근거해 차이를 설명하는 기능을 시험할 예정입니다. 이 모델 연동은 아직 구현 전입니다.

**검증 계획**
개발에 사용하지 않은 편집 영상과 무관한 영상을 테스트해 잘못 묶이는 사례를 확인합니다. 새로운 내용이 있는 영상까지 가려지는지 점검하고, 간단한 사용성 테스트를 통해 이용자가 필터의 이유를 이해하고 직접 해제할 수 있는지 살펴봅니다.

**목표**
이용자가 반복 노출을 직접 조절하면서 새로운 내용을 접할 기회를 유지하도록 돕습니다.
