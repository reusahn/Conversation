## 이번에 강화한 기능

같은 영상이라도 어떤 설명이 붙었는지에 따라 확인할 근거가 달라집니다. 원본 매칭은 유지하면서 정확한 영화 소개, 오늘 처음 촬영했다는 주장, 확인할 수 없는 질문을 다르게 처리합니다. 질문과 근거가 연결된 결과 링크를 다른 휴대전화에서 열어 재생하는 것이 핵심 데모입니다.

## 점수와 기록 원칙

5인은 공개 직무를 참고한 가상 출전팀이며 실제 인물의 참여나 승인을 뜻하지 않습니다. 기획 평가 84~87점은 실제 대회 점수나 우승 확률이 아닙니다. 100점에 필요한 실행 증거와 미확인은 그대로 남깁니다.

이 저장소가 모든 ChatGPT 대화를 자동 수집하지는 않습니다. 해당 대화 내용과 저장소 접근이 제공되는 환경에서 기록을 갱신합니다. 이전 전체 대화가 이미 저장되어 있었다고 주장하지 않습니다.
